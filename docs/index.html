MirDB

A persistent key-value store with memcached protocol compatibility. Drop-in replacement for memcached that persists your data.

Get Started View on GitHub

See It In Action

Features

Persistent Storage

Unlike memcached, MirDB persists data to disk using SSTables, ensuring your data survives restarts.

Memcached Protocol

Compatible with standard memcached text protocol. Use your existing memcached clients seamlessly.

LSM Tree Architecture

Log-Structured Merge-tree approach with memtables and multi-level SSTable compaction for optimal performance.

Skip-List Memtable

Efficient in-memory data structure providing O(log n) operations for fast reads and writes.

Automatic Compaction

Background minor and major compaction keeps the database optimized without manual intervention.

Async I/O with Tokio

Built on Tokio for high-performance async networking, handling thousands of concurrent connections.

Quick Start

Get MirDB running in minutes. Follow these simple steps to start storing your data persistently.

1 Build and Start the Server 

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build and run with Cargo
cargo run --release

# Server starts on port 12333

2 Store Data with SET 

# Connect using telnet or any memcached client
telnet localhost 12333

# SET command format: set <key> <flags> <ttl> <bytes>
set mykey 0 0 5
hello
STORED

3 Retrieve Data with GET 

# GET command retrieves stored values
get mykey
VALUE mykey 0 5
hello
END

Other Commands

MirDB supports standard memcached commands:

  • add - Add if key doesn't exist
  • replace - Replace existing key
  • delete - Delete a key
  • append - Append to value
  • prepend - Prepend to value
  • info - Database status
