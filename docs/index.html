MirDB

A Persistent Key-Value Store with Memcached Protocol

Get Started View on GitHub

Key Features

Memcached Protocol

Full compatibility with the Memcached text protocol. Use your existing memcached clients and tools without any code changes.

Persistence

Durable storage with write-ahead logging ensures your data survives restarts. Unlike memcached, your data is safely persisted to disk.

LSM Tree Storage

Log-Structured Merge tree architecture optimized for write-intensive workloads. Efficient storage with automatic level management across 7 levels.

Skip List Memtable

In-memory skip list data structure provides O(log n) operations. Fast reads and writes with efficient memory utilization for the active working set.

Automatic Compaction

Background compaction automatically merges and optimizes SSTables. Both minor (memtable flush) and major compaction maintain storage efficiency.

Architecture

MirDB implements an LSM (Log-Structured Merge) tree storage engine designed for high write throughput with efficient reads.

Write-Ahead Log (WAL)

The WAL provides durability by persisting writes before acknowledging them. Each write is first appended to the WAL, ensuring data can be recovered after crashes. WAL segments are Snappy-compressed and aligned for efficient storage.

Memtable

The memtable is an in-memory skip list data structure that accepts all incoming writes. It provides O(log n) insert and lookup operations. When the memtable reaches 4MB, it becomes immutable and a new memtable is created.

SSTable (Sorted String Table)

SSTables are immutable on-disk files storing key-value pairs sorted by key. Each SSTable contains data blocks with prefix compression, a meta block with min/max keys and Cuckoo filter, an index block for efficient lookups, and a footer with checksums.

Compaction

MirDB runs two types of compaction in background threads:

  • Minor Compaction: Flushes immutable memtables to Level 0 SSTables
  • Major Compaction: Merges SSTables between levels, removing duplicates and deleted keys

The LSM tree supports up to 7 levels, with each level 10x larger than the previous.
