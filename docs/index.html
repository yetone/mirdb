MirDB

A Persistent Key-Value Store with Memcached protocol

Get Started View on GitHub
version 0.1.0

Key Features

🔌

Memcached Protocol

Full compatibility with the Memcached text protocol. Use familiar commands like SET, GET, DELETE with existing Memcached clients.

🌲

LSM-tree Storage

Log-Structured Merge-tree architecture optimized for high write throughput and efficient storage utilization.

📋

Skip-list Memtable

In-memory skip-list data structure for fast reads and writes with O(log n) complexity.

📝

WAL Durability

Write-Ahead Log ensures crash recovery and data durability. Never lose committed data.

📦

SSTable Storage

Sorted String Tables provide efficient on-disk storage with fast sequential reads and bloom filters.

🔄

Compaction

Automatic minor and major compaction processes to merge SSTables, reclaim space, and optimize read performance.

⏰

TTL Support

Time-to-live expiration for keys. Set automatic expiration times for cached data.

Getting Started

Connect to MirDB using the Memcached protocol. Here's a quick example using telnet:

Connect to MirDB

telnet localhost 11211

Store a Value (SET Command)

Use the SET command to store a key-value pair. The syntax is: set <key> <flags> <exptime> <bytes>

set mykey 0 3600 5
hello
STORED

Retrieve a Value (GET Command)

Use the GET command to retrieve stored values:

get mykey
VALUE mykey 0 5
hello
END
