MirDB

A Persistent Key-Value Store with Memcached Protocol Support

What is MirDB? MirDB is a high-performance persistent key-value store with Memcached protocol support and LSM tree architecture.
Get Started View on GitHub

Key Features

Persistent Storage

Unlike traditional memcached, MirDB provides persistent storage. Your data survives restarts and system crashes, ensuring durability and reliability for your applications.

LSM Tree Architecture

Built with a Log-Structured Merge tree architecture for efficient write operations. Write-ahead logging (WAL) ensures durability, while compacted SSTables provide optimized read performance.

Memcached Compatibility

Full Memcached protocol support means you can use MirDB with existing memcached clients. No code changes required - just point your client to MirDB and enjoy persistence.

Architecture

MirDB uses a Log-Structured Merge (LSM) tree architecture for optimal write performance:

Write Request → WAL → Memtable → Immutable Memtables → Level 0 SSTables → Level 1+ SSTables
             ↓                        ↓                    ↓                      ↓
        (durability)           (minor compaction)  (may overlap)      (sorted, non-overlapping)

This architecture provides excellent write throughput while maintaining efficient read operations through compaction and tiered storage.

Quick Start

Installation

git clone https://github.com/yetone/mirdb
cd mirdb
cargo build --release

Running MirDB

./target/release/mirdb-server

By default, MirDB listens on 0.0.0.0:12333

Basic Usage

MirDB supports standard Memcached protocol commands. Using your favorite memcached client:

# SET command
SET key 0 3600 5
hello
STORED

# GET command
GET key
VALUE key 0 5
hello
END

# DELETE command
DELETE key
DELETED
