How It Works

MirDB uses a Log-Structured Merge-tree (LSM tree) architecture for efficient writes and reads. Data flows through the Write-Ahead Log, Memtable, and multiple SSTable levels.

WAL

Write-Ahead Log ensures durability by persisting every write before acknowledging.

Memtable

In-memory skip list structure for fast writes and recent data lookups.

SSTable

Sorted String Tables store immutable data on disk across multiple levels with compaction.
