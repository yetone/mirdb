Features

Memcached Protocol

Full Memcached protocol compatibility allows you to use existing memcached clients. Drop-in replacement for your existing infrastructure.

Persistence

Unlike traditional Memcached, MirDB persists data to disk using SSTables. Your data survives restarts and crashes.

LSM Tree Architecture

Built on Log-Structured Merge-tree architecture for optimal write performance. Automatic compaction keeps read performance fast.
