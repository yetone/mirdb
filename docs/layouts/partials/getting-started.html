Getting Started

1 Installation

Clone the repository and build with Cargo: 

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

2 Run the Server

Start MirDB with default configuration: 

./target/release/mirdb

3 Basic Operations

Connect using any memcached client and perform set/get operations: 

# Connect using telnet or nc
telnet localhost 12333

# Set a key-value pair
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END
