MirDB: A Persistent Key-Value Store with Memcached Protocol

High-performance storage with the familiarity of Memcached

Get Started

Features

Powerful capabilities for high-performance data storage

Memcached Protocol

Full compatibility with the standard Memcached text protocol. Use existing clients and tools seamlessly with GET, SET, DELETE, and more commands.

SSTables Persistence

Unlike vanilla Memcached, MirDB persists your data to disk using SSTables (Sorted String Tables) with compression and caching support.

LSM Tree Architecture

Built on a Log-Structured Merge-tree design with memtables, immutable memtables, and multi-level compaction for optimal write performance.

Async Performance

Powered by Tokio async runtime for high-performance, non-blocking I/O. Handle thousands of concurrent connections efficiently with Rust's safety guarantees.

Quick Start

Prerequisites

  • Rust toolchain - Install via rustup.rs 
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Installation

Install MirDB using Cargo:

cargo install mirdb

Running the Server

Start the MirDB server:

mirdb

The server listens on port 11211 by default (standard Memcached port).

Basic Usage

Connect using telnet or nc (netcat): 

telnet localhost 11211

SET a value:

set mykey 0 0 5
hello
STORED

GET a value:

get mykey
VALUE mykey 0 5
hello
END

Alternatively, use nc (netcat): echo "get mykey" | nc localhost 11211

Configuration

Configure MirDB using a TOML configuration file

Create a configuration file at /etc/mirdb.toml or specify a custom path using the -c flag: 

mirdb -c /path/to/config.toml

Example Configuration (mirdb.toml)

# Network configuration
addr = "0.0.0.0:12333"

# Storage settings
max_level = 7
work_dir = "/tmp/mirdb"

# SSTable configuration
sst_max_size = "100M"
mem_table_max_size = "4M"
mem_table_max_height = 32

# Memory table settings
imm_mem_table_max_count = 16

# Block configuration
block_size = "4K"
block_restart_interval = 16

# Compaction settings
l0_compaction_trigger = 4

# Background thread settings
thread_sleep_ms = 500

Configuration Options

Network

Parameter Description Default
addr Listen address and port 0.0.0.0:12333

Storage

Parameter Description Default
work_dir Data directory path /tmp/mirdb
max_level Maximum LSM tree levels 7

Memory Tables

Parameter Description Default
mem_table_max_size Max memtable size before flush 4M
mem_table_max_height Skip list max height 32
imm_mem_table_max_count Max queued immutable memtables 16

SSTables

Parameter Description Default
sst_max_size Max SSTable file size 100M
block_size Data block size 4K
block_restart_interval Key prefix restart interval 16

Compaction

Parameter Description Default
l0_compaction_trigger Level 0 files before compaction 4
thread_sleep_ms Background thread sleep interval 500ms

Size Units

Configuration supports size suffixes: K (KB), M (MB), G (GB), T (TB)
