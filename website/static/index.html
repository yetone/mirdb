MirDB: A Persistent Key-Value Store with Memcached Protocol

High-performance storage with the familiarity of Memcached

Get Started

Features

Powerful capabilities for high-performance data storage

Memcached Protocol

Full compatibility with the standard Memcached text protocol. Use existing clients and tools seamlessly with GET, SET, DELETE, and more commands.

SSTables Persistence

Unlike vanilla Memcached, MirDB persists your data to disk using SSTables (Sorted String Tables) with compression and caching support.

LSM Tree Architecture

Built on a Log-Structured Merge-tree design with memtables, immutable memtables, and multi-level compaction for optimal write performance.

Async Performance

Powered by Tokio async runtime for high-performance, non-blocking I/O. Handle thousands of concurrent connections efficiently with Rust's safety guarantees.

Quick Start

Prerequisites

  • Rust toolchain - Install via rustup.rs 
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Installation

Install MirDB using Cargo:

cargo install mirdb

Running the Server

Start the MirDB server:

mirdb

The server listens on port 11211 by default (standard Memcached port).

Basic Usage

Connect using telnet or nc (netcat): 

telnet localhost 11211

SET a value:

set mykey 0 0 5
hello
STORED

GET a value:

get mykey
VALUE mykey 0 5
hello
END

Alternatively, use nc (netcat): echo "get mykey" | nc localhost 11211

Configuration

Configure MirDB using mirdb.toml
