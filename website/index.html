MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance persistent key-value store written in Rust. Drop-in replacement for memcached with durable storage powered by LSM-tree architecture.

Get Started View on GitHub

Key Features

Memcached Protocol Compatible

Use existing memcached clients seamlessly. Supports SET, GET, DELETE, ADD, REPLACE, APPEND, and PREPEND commands.

Persistent Storage with SSTables

Unlike memcached, MirDB persists data to disk using Sorted String Tables (SSTables) for durability.

LSM-Tree Architecture

Log-Structured Merge-tree design with memtables, immutable memtables, and multi-level SSTable compaction.

High Performance with Rust

Written in Rust for memory safety and high performance. Async I/O powered by Tokio runtime.

WAL for Crash Recovery

Write-ahead logging ensures data durability and enables recovery after unexpected crashes.

Configurable Compaction

Minor and major compaction strategies to optimize storage efficiency and read performance.

Getting Started

1. Clone the Repository

git clone https://github.com/yetone/mirdb.git
cd mirdb

2. Build the Project

cargo build --release

3. Run MirDB Server

./target/release/mirdb-server

4. Connect with Any Memcached Client

# Using telnet
telnet localhost 12333

# Example commands
set mykey 0 0 5
hello
STORED

get mykey
VALUE mykey 0 5
hello
END
