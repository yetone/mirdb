MirDB

A persistent key-value store with memcached compatibility. Get the speed of in-memory caching with the durability of disk-based storage.

Get Started View on GitHub

Key Features

Built for performance, designed for simplicity

Memcached Protocol Compatibility

Drop-in replacement for memcached. Use your existing memcached clients without code changes. Full support for SET, GET, DELETE, and more commands.

Persistent Storage

Data survives restarts with SSTable-based durable storage. Your data is safely persisted to disk while maintaining fast read and write performance.

LSM Tree Architecture

Write-optimized design using Log-Structured Merge tree for high write throughput. Automatic compaction keeps read performance excellent.

Async Networking

Built on Tokio for high-performance async I/O. Handle thousands of concurrent connections efficiently with minimal resource usage.

Getting Started

# Clone the repository
git clone https://github.com/mirdb/mirdb.git
cd mirdb

# Build and run
cargo build --release
./target/release/mirdb-server

# Connect with any memcached client
telnet localhost 12333

Configuration

Tune MirDB to your needs with these configurable parameters

Example Configuration (TOML)

addr = "0.0.0.0:12333"

max_level = 7
work_dir = "/tmp/mirdb"

sst_max_size = "100M"
mem_table_max_size = "4M"
mem_table_max_height = 32

imm_mem_table_max_count = 16

block_size = "4K"
block_restart_interval = 16

l0_compaction_trigger = 4

thread_sleep_ms = 500

Configuration Parameters

Parameter Description Default
addr Listen address and port for the server 0.0.0.0:12333
max_level Maximum number of LSM tree levels 7
work_dir Data directory path for storage files /tmp/mirdb
mem_table_max_size Maximum memtable size before flush to disk 4MB
sst_max_size Maximum SSTable file size 100MB
l0_compaction_trigger Number of Level 0 files before compaction triggers 4
