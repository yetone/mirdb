MirDB

Persistent Key-Value Store with Memcached Compatibility

A high-performance, durable caching solution that combines the simplicity of memcached with the reliability of persistent storage.

Get Started View on GitHub

Why Choose MirDB?

Persistence

LSM tree-based storage with Write-Ahead Logging (WAL) ensures your data survives restarts and crashes. Never lose cached data again with durable, disk-backed storage.

Compatibility

Drop-in memcached protocol support means you can use your existing clients and tools. Migrate seamlessly without changing a single line of application code.

Performance

Rust-powered async I/O with Tokio delivers exceptional throughput and low latency. Benefit from memory safety and zero-cost abstractions without sacrificing speed.

Core Features

GET/SET/DELETE with TTL

Full support for standard cache operations with configurable time-to-live expiration.

Background Compaction

Automatic minor and major compaction keeps storage optimized without manual intervention.

Crash Recovery

Write-ahead logging ensures data integrity even after unexpected shutdowns.

TOML Configuration

Simple, human-readable configuration files for easy deployment and management.

7-Level LSM Tree

Multi-level storage hierarchy with optimized merging for balanced read/write performance.

Snappy Compression

Efficient data compression reduces disk usage while maintaining fast access times.

Getting Started

1. Build from Source

git clone https://github.com/mirdb/mirdb.git
cd mirdb
cargo build --release

2. Configure

# etc/mirdb.toml
addr = "0.0.0.0:12333"
max_level = 7
work_dir = "/tmp/mirdb"
sst_max_size = "100M"
mem_table_max_size = "4M"

3. Run

./target/release/mirdb-server -c etc/mirdb.toml

4. Connect

# Use any memcached client
telnet localhost 12333
set mykey 0 3600 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
