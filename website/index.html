Key Features

Tokio with Memcached Protocol

Built on Tokio's async runtime with full Memcached protocol support, enabling seamless integration with existing Memcached clients and infrastructure.

Memtable with Skiplist

In-memory storage using efficient skiplist data structures for fast writes and ordered key traversal with O(log n) complexity.

Minor Compaction

Automatically flushes memtable data to disk as sorted string tables (SSTables), ensuring data durability while maintaining write performance.

Major Compaction

Periodically merges and compacts SSTables to reclaim space, remove deleted entries, and optimize read performance over time.

Quickstart

1

Clone the repository

git clone https://github.com/yetone/mirdb.git
2

Build the project

cd mirdb && cargo build --release
3

Run MirDB

./target/release/mirdb
