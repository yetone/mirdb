MirDB

Persistent Key-Value Store with Memcached Compatibility

A drop-in replacement for memcached that persists your data to disk. Built with Rust for performance and reliability, using an LSM-tree architecture for efficient writes and reads.

Get Started View on GitHub

Key Features

Everything you need for a reliable, persistent key-value store

Memcached Protocol Compatibility

Use your existing memcached clients without any code changes. MirDB implements the standard memcached text protocol, making it a true drop-in replacement for your caching layer.

Persistent Storage

Unlike memcached, your data survives restarts. MirDB stores data in SSTables (Sorted String Tables) on disk, ensuring durability without sacrificing the speed you expect.

LSM-Tree Architecture

Built on a Log-Structured Merge-tree design for write-optimized performance. Data flows through memtables to sorted SSTables across multiple levels, balancing write speed with read efficiency.

Async Networking (Tokio)

Powered by Tokio, Rust's leading async runtime. Handle thousands of concurrent connections efficiently with non-blocking I/O and minimal resource consumption.

Background Compaction

Automatic background threads handle both minor and major compaction. Your data stays organized and queries remain fast without any manual intervention or downtime.

Write-Ahead Logging

Every write is logged before being applied, ensuring crash recovery and data integrity. Even in unexpected shutdowns, your data remains safe and recoverable.

Quick Start

Get MirDB running in minutes

1. Install

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

2. Run

./target/release/mirdb-server

3. Connect

# Using telnet or any memcached client
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello

# Get it back
get mykey

How It Works

LSM-Tree data flow from write to disk

Write Request
    │
    ▼
┌─────────┐
│   WAL   │──── Write-Ahead Log for durability
└────┬────┘
     │
     ▼
┌──────────┐
│ Memtable │──── Active in-memory skip list
└────┬─────┘
     │ (when full)
     ▼
┌────────────────┐
│ Imm Memtables  │──── Immutable memtables queue
└───────┬────────┘
        │ (minor compaction)
        ▼
┌───────────────┐
│ Level 0 SSTs  │──── Recently flushed, may overlap
└───────┬───────┘
        │ (major compaction)
        ▼
┌───────────────┐
│ Level 1+ SSTs │──── Sorted, non-overlapping
└───────────────┘

Supported Commands

Standard memcached commands plus MirDB extras

Command Description
SET Store a key-value pair
GET Retrieve value by key
GETS Retrieve value with CAS token
ADD Store only if key doesn't exist
REPLACE Store only if key exists
APPEND Append data to existing value
PREPEND Prepend data to existing value
DELETE Remove a key-value pair
INFO Get server statistics (MirDB)
MAJOR_COMPACTION Trigger manual compaction (MirDB)
