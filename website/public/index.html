MirDB

A persistent key-value store with Memcached protocol compatibility, written in Rust

Get Started View on GitHub

Key Features

Built for performance, reliability, and developer experience

🔌

Memcached Protocol Compatibility

Drop-in compatibility with existing Memcached clients. Use your favorite Memcached libraries and tools without any code changes.

🌲

LSM-Tree Storage Architecture

Efficient storage with optimized write and read paths. The LSM-tree architecture provides high write throughput while maintaining fast read performance.

📝

Write-Ahead Logging (WAL)

Data durability through crash-safe logging. Every write is persisted to the WAL before being acknowledged, ensuring no data loss.

🔄

Minor & Major Compaction

Automatic space reclamation and read optimization. Compaction merges and removes obsolete data, keeping storage efficient and queries fast.

⚡

LRU Block Cache

Fast reads through intelligent caching. Frequently accessed data blocks are kept in memory, dramatically reducing disk I/O for hot data.

🔍

Cuckoo Filter

Quick key existence checks without disk access. The Cuckoo filter efficiently determines if a key might exist, avoiding unnecessary disk lookups.

📦

Snappy Compression

Reduced storage footprint with fast compression. Snappy provides excellent compression ratios with minimal CPU overhead.

Quick Start

Get up and running with MirDB in minutes

1. Installation

Clone the repository and build MirDB using Cargo:

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

2. Start the Server

Run MirDB with default settings:

# Start MirDB server
cargo run --release

# Or run the binary directly
./target/release/mirdb

By default, MirDB listens on port 11211 (standard Memcached port).

3. Basic Usage

Connect using any Memcached client or telnet. Here are common commands:

# Connect to MirDB
telnet localhost 11211

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

# Delete a key
delete mykey
DELETED

4. Using with Memcached Clients

MirDB is compatible with standard Memcached clients:

# Python example with pymemcache
from pymemcache.client import Client

client = Client('localhost:11211')

# Set a value
client.set('key', 'value')

# Get the value
result = client.get('key')
print(result)  # b'value'

Supported Commands

Getter Commands

  • get <key> [<key> ...] - Retrieve one or more values
  • gets <key> [<key> ...] - Get with CAS token

Setter Commands

  • set - Store a value
  • add - Store only if key doesn't exist
  • replace - Store only if key exists
  • append - Append to existing value
  • prepend - Prepend to existing value

Other Commands

  • delete - Remove a key
  • info - Server information
  • major_compaction - Trigger manual compaction
