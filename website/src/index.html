MirDB

Persistent Key-Value Store with Memcached Protocol Compatibility

MirDB combines the simplicity of memcached with the durability of persistent storage. Built with Rust and powered by LSM tree architecture, it offers high-performance data operations while ensuring your data survives restarts and crashes.

Get Started View on GitHub

Key Features

Memcached Compatible

Use existing memcached clients seamlessly. Drop-in replacement with full protocol support for GET, SET, DELETE, and more.

Persistent Storage

Data survives restarts with SSTable storage. Write-ahead logging ensures durability even during unexpected crashes.

High Performance

LSM tree architecture with Tokio-based async I/O delivers exceptional throughput and low latency operations.

Quick Start

# Start MirDB server
mirdb -c config.toml

# Connect with any memcached client
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
