MirDB

A Persistent Key-Value Store with Memcached Protocol

Quick Start View on GitHub

Quick Start

Get up and running with MirDB in minutes

Installation 
# Clone the repository
git clone https://github.com/mirdb/mirdb.git
cd mirdb

# Build with Cargo
cargo build --release

# Run MirDB server
./target/release/mirdb -c etc/mirdb.toml
Basic Usage 
# Connect using any memcached client
# Default port: 12333

# Using telnet
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello

# Get a value
get mykey

Default Configuration

  • Listen Address: 0.0.0.0:12333
  • Work Directory: /tmp/mirdb
  • Memtable Size: 4MB
  • SSTable Max Size: 100MB
  • Max LSM Levels: 7

Configure via mirdb.toml or command-line flags.
