Key Features

Memcached Protocol

Drop-in replacement for memcached. Use your existing client libraries and code without any modifications.

Data Persistence

Your data survives restarts. Built-in persistence ensures no data loss during server reboots or crashes.

LSM Tree Architecture

High-performance storage engine using Log-Structured Merge trees for optimized write throughput.

Quick Start

Get up and running with MirDB in minutes

Installation 
# Clone the repository
git clone https://github.com/mirdb/mirdb.git
cd mirdb

# Build with Cargo
cargo build --release

# Run MirDB server
./target/release/mirdb -c etc/mirdb.toml
Basic Usage 
# Connect using any memcached client
# Default port: 12333

# Using telnet
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello

# Get a value
get mykey

Default Configuration

  • Listen Address: 0.0.0.0:12333
  • Work Directory: /tmp/mirdb
  • Memtable Size: 4MB
  • SSTable Max Size: 100MB
  • Max LSM Levels: 7

Configure via mirdb.toml or command-line flags.

Supported Operations

MirDB implements the memcached text protocol

  • GET Retrieve one or more keys
  • SET Store a key-value pair
  • ADD Store only if key doesn't exist
  • REPLACE Store only if key exists
  • DELETE Remove a key
  • APPEND Append data to existing value
  • PREPEND Prepend data to existing value

Configure via mirdb.toml or command-line flags. See documentation for all options.
