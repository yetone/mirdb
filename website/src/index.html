MirDB

A Persistent Key-Value Store with Memcached Protocol

Built on LSM tree architecture with Tokio async runtime. Use your existing memcached clients with disk persistence.

Get Started View on GitHub

Quick Start

Get up and running with MirDB in minutes

1 Install MirDB

Install MirDB using Cargo or download the pre-built binary.

bash 
# Install with Cargo
cargo install mirdb

# Or download pre-built binary
curl -L https://github.com/akiozihao/mirdb/releases/latest/download/mirdb -o mirdb
chmod +x mirdb

2 Start the Server

Run MirDB with your preferred configuration options.

bash 
# Start with default settings (port 11211, data in ./mirdb-data)
mirdb

# Or configure port and data directory
mirdb --port 11211 --data-dir /var/lib/mirdb

3 Connect and Use

Use any memcached client to interact with MirDB using standard commands.

terminal 
# Connect using telnet or nc
telnet localhost 11211

# SET a key-value pair (flags=0, exptime=0, bytes=5)
SET mykey 0 0 5
hello
STORED

# GET the value
GET mykey
VALUE mykey 0 5
hello
END

# DELETE a key
DELETE mykey
DELETED

Protocol Reference

MirDB implements the memcached text protocol, allowing you to use existing memcached clients. Additionally, MirDB provides custom commands for database management.

Standard Memcached Commands

Command Syntax Description
SET SET <key> <flags> <exptime> <bytes> Store data under the specified key
GET GET <key> Retrieve data for the specified key
DELETE DELETE <key> Delete the specified key from the store
ADD ADD <key> <flags> <exptime> <bytes> Store data only if the key does not exist
REPLACE REPLACE <key> <flags> <exptime> <bytes> Store data only if the key already exists
FLUSH_ALL FLUSH_ALL [delay] Invalidate all existing items

MirDB-Specific Commands

These commands are unique to MirDB and not part of the standard memcached protocol.

Command Syntax Description
INFOMirDB INFO Get server statistics and database information
MAJOR_COMPACTIONMirDB MAJOR_COMPACTION Trigger manual compaction of SSTable files
