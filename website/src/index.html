MirDB

Persistent Key-Value Store with Memcached Protocol

MirDB combines the simplicity and speed of Memcached with durable persistence. Built in Rust with an LSM tree architecture, it provides high-performance key-value storage that survives restarts while remaining fully compatible with existing Memcached clients.

Get Started View on GitHub

Key Features

Memcached Compatible

Drop-in replacement for existing memcached deployments. Use your existing clients without any code changes.

Persistent Storage

Data survives restarts using SSTable architecture. Never lose your cached data again.

High Performance

LSM tree design optimized for write-heavy workloads. Built in Rust for maximum efficiency.

Simple Configuration

TOML-based configuration with sensible defaults. Get started in minutes, not hours.
