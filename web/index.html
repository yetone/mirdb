MirDB

Persistent Key-Value Store with Memcached Protocol

Get Started View on GitHub

Key Features

Memcached Protocol

Full compatibility with standard Memcached text protocol. Use existing memcached clients seamlessly without any code changes.

Persistent Storage

Data persists to disk using LSM Tree architecture with SSTables. Survive restarts without losing your cache data.

High Performance

Built with Rust for blazing-fast performance. Async I/O with Tokio ensures maximum throughput and low latency.

Easy Configuration

Simple TOML-based configuration. Sensible defaults get you started quickly with options to tune for your workload.

Quick Start

# Clone the repository
git clone https://github.com/example/mirdb.git
cd mirdb

# Build and run
cargo build --release
./target/release/mirdb-server

# Connect with any memcached client
telnet localhost 12333
