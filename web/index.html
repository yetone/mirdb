Get Started

Features

🔌

Memcached Protocol

Compatible with standard memcached text protocol. Use existing memcached clients to connect seamlessly.

💾

Data Persistence

Data is persisted to disk using SSTables (Sorted String Tables). Your data survives restarts.

🌳

LSM Tree Architecture

Uses Log-Structured Merge-tree approach with memtables, immutable memtables, and multi-level SSTable compaction.

🦀

Rust Implementation

Built with Rust for memory safety, performance, and reliability. No garbage collection pauses.

Usage Demonstration

Basic operations using standard memcached protocol - set, get, and delete commands.

Quick Start

Prerequisites

Make sure you have Rust toolchain installed. If not, install it from rustup.rs.

Installation

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

Configuration

Create a configuration file (e.g., mirdb.toml):

# MirDB Configuration
addr = "0.0.0.0:12333"
max_level = 7
work_dir = "/tmp/mirdb"
sstable_max_size = 104857600  # 100MB
memtable_max_size = 4194304   # 4MB
block_size = 4096             # 4KB

# Web server configuration
web_enabled = true
web_port = 8080
web_static_dir = "./web"

Running the Server

# Start MirDB server
./target/release/mirdb-server -c mirdb.toml

Basic Usage

Connect using any memcached client or telnet:

# Connect with telnet
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get a value
get mykey
VALUE mykey 0 5
hello
END

# Delete a value
delete mykey
DELETED
