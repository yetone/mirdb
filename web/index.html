Features

🔌

Memcached Protocol

Compatible with standard memcached text protocol. Use your existing memcached clients seamlessly.

💾

Data Persistence

Data persisted to disk using SSTables. Your data survives restarts and crashes.

🌳

LSM Tree

Efficient Log-Structured Merge-tree architecture for high write throughput.

⚙

Rust Implementation

Built with Rust for performance, memory safety, and reliability.

Quick Start

Prerequisites

  • Rust toolchain (rustc, cargo) - Install via rustup
  • A memcached client (telnet, nc, or any memcached library)

Installation

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

Configuration

Create a configuration file or use the default settings:

# mirdb.toml
addr = "0.0.0.0:12333"
work_dir = "/tmp/mirdb"
level_count = 7

Basic Usage

# Start the server
./target/release/mirdb-server -c mirdb.toml

# Connect with telnet and use memcached commands
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

# Delete the key
delete mykey
DELETED
