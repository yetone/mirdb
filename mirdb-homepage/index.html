MirDB

A Persistent Key-Value Store with Memcached Protocol

View on GitHub Get Started

Key Features

Memcached Protocol

Full compatibility with the Memcached protocol, allowing seamless integration with existing Memcached clients and tools.

Persistent Storage

Unlike traditional Memcached, MirDB provides persistent storage ensuring your data survives restarts and failures.

Skip-List Memtable

Efficient in-memory data structure using skip-list based memtable for fast reads and writes.

Compaction

Automatic minor and major compaction to optimize storage space and maintain consistent read performance.

Built with Rust

Implemented in Rust for memory safety, high performance, and reliability without garbage collection overhead.

Quick Start

Installation

cargo install mirdb

Start the Server

mirdb-server

Basic Usage

telnet localhost 11211
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
