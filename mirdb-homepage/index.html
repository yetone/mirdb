MirDB

A Persistent Key-Value Store with Memcached protocol

Lightning-fast key-value storage with the familiar Memcached interface. Built for durability with LSM tree storage and automatic compaction.

Get Started View Source

Features

Memcached Protocol

Compatible with standard memcached clients for familiar, painless usage. Drop-in replacement for your existing infrastructure.

Persistence

Your data survives restarts. Unlike traditional memcached, MirDB persists data to disk using SSTables for durability.

LSM Tree

Log-Structured Merge-tree provides efficient storage with excellent write performance and automatic data organization.

Skip List Memtable

Fast in-memory operations with skip list data structure for O(log n) lookups, insertions, and deletions.

Compaction

Automatic data optimization through multi-level SSTable compaction. Background processes keep storage efficient.

Raft (Future)

Planned distributed consensus support for high availability and fault tolerance across multiple nodes.

Usage

Connect to MirDB using any standard memcached client. Here's a simple example using telnet:

Quick Example

# Connect to MirDB server
telnet localhost 11211

# Set a key-value pair
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

MirDB supports all standard memcached commands including set, get, delete, and more.
