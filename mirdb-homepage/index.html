MirDB

A persistent key-value store with Memcached protocol compatibility, written in Rust

Disk Persistence Memcached Protocol Written in Rust

Key Features

Memcached Protocol

Full compatibility with the Memcached text protocol. Supports essential commands including SET, GET, and DELETE operations, allowing seamless integration with existing Memcached clients and tools.

Disk Persistence

Unlike pure Memcached, MirDB persists data to disk ensuring durability. Your data survives server restarts and crashes, combining the speed of in-memory caching with the reliability of persistent storage.

LSM Tree Architecture

Built on a Log-Structured Merge tree design with WAL (Write-Ahead Log) for crash recovery, an in-memory Memtable for fast writes, and SSTables for efficient disk storage and retrieval.

Built with Rust

Written in Rust for memory safety and high performance. Powered by Tokio for async I/O, delivering excellent throughput while preventing common memory-related bugs and data races.
