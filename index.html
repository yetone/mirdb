MirDB

A Persistent Key-Value Store with Memcached Protocol Compatibility. Built with Rust and LSM Tree architecture for high performance and durability.

Get Started View on GitHub

Key Features

MirDB combines the simplicity of memcached with the durability of persistent storage.

Memcached Protocol Compatible

Drop-in replacement for memcached. Use your existing memcached clients without any code changes.

Persistent Storage

Data survives restarts with LSM Tree architecture. Write-ahead logging ensures durability.

High Performance

Built with Rust and Tokio for async networking. Skip list memtable for fast in-memory operations.

Efficient Compression

Snappy compression reduces storage footprint while maintaining fast read/write speeds.

Automatic Compaction

Minor and major compaction keeps storage efficient. Manual compaction available via commands.

Configurable

Tune memtable size, SSTable parameters, and compaction behavior to match your workload.

Supported Commands

MirDB implements the memcached text protocol with additional MirDB-specific commands.

Storage Commands
SET
Store a key-value pair, overwriting any existing value
ADD
Store a key-value pair only if the key does not already exist
REPLACE
Store a key-value pair only if the key already exists
APPEND
Append data to an existing key's value
PREPEND
Prepend data to an existing key's value
Retrieval Commands
GET
Retrieve the value for one or more keys
GETS
Retrieve values with CAS token for compare-and-swap operations
Deletion Commands
DELETE
Remove a key and its associated value from the database
MirDB-Specific Commands
INFO MirDB
Display database status, level information, and statistics
MAJOR_COMPACTION MirDB
Trigger a manual major compaction to optimize storage

Quick Start

Get MirDB running in minutes with these simple steps.

Installation

# Clone the repository git clone https://github.com/yetone/mirdb.git cd mirdb # Build the project cargo build --release # Run with default configuration ./target/release/mirdb-server -c etc/mirdb.toml

Usage Example

# Connect to MirDB $ telnet localhost 12333 # Store a value set mykey 0 0 5 hello STORED # Retrieve the value get mykey VALUE mykey 0 5 hello END # Delete the value delete mykey DELETED

Configuration

MirDB is highly configurable to match your workload requirements.

Parameter Default Value Description
addr 0.0.0.0:12333 Listen address and port
max_level 7 Maximum LSM tree levels
mem_table_max_size 4MB Maximum memtable size before flush
sst_max_size 100MB Maximum SSTable file size
block_size 4KB SSTable block size
