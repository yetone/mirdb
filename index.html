A Persistent Key-Value Store with Memcached Protocol

View on GitHub Get Started

Key Features

Memcached Compatible

Use existing Memcached clients and protocols. Drop-in replacement for your current caching infrastructure.

Persistent Storage

Data survives restarts with LSM-tree architecture. Your cache becomes durable storage.

High Performance

Async I/O with Tokio for maximum throughput. Built in Rust for speed and safety.

Efficient Memory

Skip list memtable for fast in-memory operations. Optimized for both read and write workloads.

Automatic Compaction

Background minor and major compaction keeps storage efficient without manual intervention.

Rust Powered

Memory safe without garbage collection. Fearless concurrency with zero-cost abstractions.

See It In Action

Getting Started

# Install via cargo
cargo install mirdb

# Start the server
mirdb-server --port 11211

# Use with any Memcached client
printf "set mykey 0 0 5\r\nhello\r\n" | nc localhost 11211
