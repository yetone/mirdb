Key Features

Memcached Protocol Compatibility

Fully compatible with the standard memcached text protocol. Use your existing memcached clients to connect seamlessly without any code changes.

Persistent Storage with SSTables

Unlike traditional memcached, MirDB persists your data to disk using SSTables (Sorted String Tables), ensuring data durability even after restarts.

LSM Tree Architecture

Built on a Log-Structured Merge-tree data structure that provides excellent write performance and efficient storage through multi-level compaction.

Configurable Compaction

Fine-tune the compaction strategy to match your workload. Configure L0 trigger thresholds, compaction intervals, and multi-level merging behavior.

Async Networking with Tokio

Powered by Tokio's async runtime for high-performance, non-blocking I/O operations. Handle thousands of concurrent connections efficiently.
