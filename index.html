MirDB

Persistent Key-Value Store with Memcached Protocol

A fast, reliable key-value store written in Rust. Use your existing memcached clients with built-in persistence powered by LSM-tree architecture.

Get Started View on GitHub

Key Features

Memcached Compatible

Use existing memcached clients and libraries. Drop-in replacement with zero code changes.

Built-in Persistence

Unlike memcached, your data survives restarts. SSTables ensure durability without sacrificing speed.

LSM-Tree Engine

Write-optimized storage with automatic compaction. Handles high write throughput efficiently.

Simple Configuration

TOML-based configuration with sensible defaults. Get started with minimal setup.

Quick Start

Get up and running with MirDB in minutes. It's as simple as using memcached.

Start the Server

# Start MirDB server with configuration file
mirdb -c /path/to/config.toml

# Or use default configuration
mirdb

Connect and Use

# Connect with any memcached client (e.g., telnet)
telnet localhost 12333

# Store a value with SET command
set mykey 0 0 5
hello
STORED

# Retrieve the value with GET command
get mykey
VALUE mykey 0 5
hello
END

# Delete a key
delete mykey
DELETED

Supported Commands

GET SET ADD REPLACE DELETE APPEND PREPEND

Getting Started

Configuration Example

# config.toml
[server]
listen = "0.0.0.0:12333"

[storage]
work_dir = "/var/lib/mirdb"
max_lsm_levels = 7
sstable_max_size = 104857600  # 100MB
memtable_max_size = 4194304   # 4MB
block_size = 4096             # 4KB

Default Values

Parameter Default Value
Listen Address 0.0.0.0:12333
Max LSM Levels 7
Work Directory /tmp/mirdb
SSTable Max Size 100MB
Memtable Max Size 4MB
Block Size 4KB
