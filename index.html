Key Features

⚡

Memcached Compatible

Full support for memcached text protocol. Drop-in replacement for existing memcached applications.

💾

Persistent Storage

SSTable-based persistence ensures data survives restarts. No more data loss on server reboot.

🌳

LSM Tree Architecture

Log-Structured Merge tree provides excellent write performance with efficient read operations.

🚀

Async Performance

Built with Tokio async runtime for high-performance I/O and concurrency.

🔄

Automatic Compaction

Background minor and major compaction keeps storage optimized without manual intervention.

🦀

Built with Rust

Memory-safe, fast, and reliable. Enjoy Rust's performance and safety guarantees.

Architecture

Write Path

  1. Writes are first appended to the Write-Ahead Log (WAL)
  2. Data is then inserted into the in-memory Memtable (skip list)
  3. WAL ensures durability - data persists even after crashes

Read Path

  1. Lookups first check the Memtable (most recent data)
  2. If not found, search through SSTables from newest to oldest
  3. Bloom filters optimize reads by avoiding unnecessary disk I/O

Compaction

  1. Minor compaction: Memtable flushed to new SSTable when full
  2. Major compaction: Multiple SSTables merged to remove duplicates and deleted keys

Getting Started

Installation

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

# Run the server
./target/release/mirdb-server

Quick Example

# Connect using telnet or netcattelnet localhost 12333

# Set a key-value pairset mykey 0 0 5hello

# Get the valueget mykey

# Expected response:VALUE mykey 0 5helloEND

# Delete a keydelete mykey

Supported Commands

Memcached Protocol

  • SET - Store a value
  • GET - Retrieve a value
  • DELETE - Remove a key
  • ADD - Store only if key doesn't exist
  • REPLACE - Store only if key exists
  • APPEND - Append to existing value
  • PREPEND - Prepend to existing value

MirDB Specific

  • INFO - Get server information
  • MAJOR_COMPACTION - Trigger major compaction

Default Configuration

Setting Default Description
listen_addr 0.0.0.0:12333 Server bind address
max_lsm_levels 7 Maximum number of LSM levels
sstable_max_size 100MB Maximum size of SSTables before compaction
memtable_max_size 4MB Maximum size of memtable before flush
