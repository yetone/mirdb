MirDB

A Persistent Key-Value Store with Memcached Protocol. It is painless as using memcached, but with disk persistence powered by Rust.

Get Started View on GitHub

Key Features

🔌

Memcached Compatible

Drop-in replacement for memcached clients. Use the familiar text protocol you already know.

💾

Persistent Storage

SSTable-based disk persistence ensures your data survives restarts and crashes.

⚡

High Performance

Rust-powered async I/O with Tokio for blazing fast network operations.

🌳

LSM Tree Architecture

Efficient write-heavy workloads with Log-Structured Merge Tree design.

📋

Skip List Memtable

Fast in-memory operations with concurrent skip list implementation.

🗘

Automatic Compaction

Both minor and major compaction support to optimize storage efficiency.

Usage Example

Connect via telnet and use standard memcached commands

Terminal - memcached protocol example 
# Connect to MirDB server
$ telnet localhost 12333
Trying 127.0.0.1...
Connected to localhost.

# Store a key-value pair
set mykey 0 0 5
hello
STORED

# Retrieve the value
get mykey
VALUE mykey 0 5
hello
END

# Delete the key
delete mykey
DELETED

Quick Start

1

Clone the repository

git clone https://github.com/yetone/mirdb.git
2

Build the project

cargo build --release
3

Run MirDB server

./target/release/mirdb-server
4

Connect and use

telnet localhost 12333
