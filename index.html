MirDB

A persistent key-value store with Memcached protocol support

Built in Rust with LSM tree architecture for efficient storage. Drop-in replacement for Memcached with data persistence using SSTables.

Get Started View on GitHub

Key Features

Memcached Protocol

Compatible with the standard Memcached text protocol. Existing clients work seamlessly.

Persistent Storage

Unlike Memcached, MirDB persists data to disk using SSTables (Sorted String Tables).

LSM Tree Architecture

Log-Structured Merge-tree with memtables, immutable memtables, and multi-level compaction.

Async Rust + Tokio

Built with async Rust and Tokio for high-performance concurrent networking.

Getting Started

Installation

Option 1: Install via Cargo

cargo install mirdb

Option 2: Build from Source

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

Starting the Server

# Run with default configuration
./target/release/mirdb-server

# Or run with custom config file
./target/release/mirdb-server -c etc/mirdb.toml

The server will start listening on 0.0.0.0:12333 by default.
