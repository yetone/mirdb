MirDB

Persistent key-value store with memcached protocol

A high-performance, persistent key-value database that speaks the memcached protocol. Built with Rust for reliability and speed.

Get Started View on GitHub

Key Features

MirDB brings together the best of both worlds: memcached's simple protocol and persistent storage for data durability.

Memcached Compatible

Full compatibility with the memcached text protocol. Use your existing memcached clients seamlessly - no code changes required. Supports SET, GET, DELETE, ADD, REPLACE, APPEND, PREPEND, and more.

Persistent Storage

Unlike memcached, your data survives restarts. MirDB uses SSTables (Sorted String Tables) to persist data to disk, ensuring data durability and crash recovery through Write-Ahead Logging (WAL).

High Performance

Built on an LSM tree (Log-Structured Merge-tree) architecture with async I/O powered by Tokio. Features efficient skip list memtables, multi-level compaction, and optimized read/write paths for maximum throughput.

Quick Start

Installation

Clone and build MirDB using Cargo:

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

# Run MirDB with configuration
cargo run --release -- -c etc/mirdb.toml

Basic Usage

Connect to MirDB using telnet or any memcached client:

# Connect with telnet
telnet localhost 12333

# Store a value
set mykey 0 0 5
hello
STORED

# Retrieve the value
get mykey
VALUE mykey 0 5
hello
END

# Delete the key
delete mykey
DELETED

Or use netcat for quick testing:

# Using nc (netcat)
echo -e "set foo 0 0 3\r\nbar\r" | nc localhost 12333

Configuration

Create a configuration file in TOML format:

# etc/mirdb.toml
addr = "0.0.0.0:12333"
max_level = 7
work_dir = "/tmp/mirdb"
sst_max_size = "100M"
mem_table_max_size = "4M"
block_size = "4K"
l0_compaction_trigger = 4

Commands Reference

MirDB implements the memcached text protocol, supporting the following commands:

SET

Store a key-value pair

set <key> <flags> <exptime> <bytes> [noreply]\r\n<data>\r\n
Example: 
set mykey 0 3600 5\r\nhello\r\n

GET

Retrieve one or more keys

get <key> [<key2> ...]
Example: 
get mykey

DELETE

Remove a key from the database

delete <key> [noreply]
Example: 
delete mykey

ADD

Store only if key doesn't exist

add <key> <flags> <exptime> <bytes> [noreply]\r\n<data>\r\n
Example: 
add newkey 0 0 5\r\nvalue\r\n

REPLACE

Store only if key exists

replace <key> <flags> <exptime> <bytes> [noreply]\r\n<data>\r\n
Example: 
replace mykey 0 0 8\r\nnewvalue\r\n

APPEND

Append data to existing value

append <key> <flags> <exptime> <bytes> [noreply]\r\n<data>\r\n
Example: 
append mykey 0 0 6\r\n_world\r\n

PREPEND

Prepend data to existing value

prepend <key> <flags> <exptime> <bytes> [noreply]\r\n<data>\r\n
Example: 
prepend mykey 0 0 6\r\nhello_\r\n

INFO

Display database status and level information

info
Example: 
info

MAJOR_COMPACTION

Trigger manual compaction of SSTables

major_compaction
Example: 
major_compaction

Response Codes

Code Description
STOREDData stored successfully
NOT_STOREDData not stored (condition not met for add/replace)
EXISTSCAS check failed
NOT_FOUNDKey not found (for delete/replace)
DELETEDKey deleted successfully
ERRORUnknown command
CLIENT_ERROR <msg>Client input error
SERVER_ERROR <msg>Server error
