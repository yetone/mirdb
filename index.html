MirDB

Persistent Key-Value Store with Memcached Protocol

Drop-in replacement for memcached with durable storage. Built with Rust for reliability and performance.

Get Started View on GitHub

Key Features

Memcached Protocol Compatible

Use your existing memcached clients. MirDB speaks the same protocol, making migration seamless.

Persistent Storage

Unlike memcached, your data survives restarts. MirDB persists to disk using SSTables for durability.

LSM Tree Architecture

Built on a Log-Structured Merge-tree for optimized write performance and efficient compaction.

Architecture Overview

MirDB uses a Log-Structured Merge-tree (LSM tree) architecture for optimized write performance and efficient data persistence.

Getting Started

Installation

Install MirDB using Cargo, Rust's package manager:

cargo install mirdb-server

Or build from source:

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

Start the Server

Run MirDB with default configuration:

mirdb-server

By default, MirDB listens on 0.0.0.0:12333.

Basic Operations

Connect using any memcached client or telnet. Here are the basic SET and GET operations:

SET Operation

Store a key-value pair:

# Using telnet
telnet localhost 12333

# SET command: SET <key> <flags> <exptime> <bytes>
set mykey 0 0 5
hello
STORED

GET Operation

Retrieve a value by key:

# GET command: GET <key>
get mykey
VALUE mykey 0 5
hello
END

Using Python Client

import memcache

# Connect to MirDB
client = memcache.Client(['localhost:12333'])

# SET operation
client.set('user:1', 'John Doe')

# GET operation
value = client.get('user:1')
print(value)  # Output: John Doe
