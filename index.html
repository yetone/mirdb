Why Choose MirDB?

Three key benefits that set MirDB apart

🔌

Memcached Protocol Support

Drop-in replacement for memcached with full protocol compatibility. Use your existing memcached clients and code with zero modifications required.

💾

Persistence

Your data survives restarts with built-in durability. Unlike traditional memcached, MirDB ensures your cached data is never lost unexpectedly.

🌲

LSM Tree Architecture

Built on efficient Log-Structured Merge Tree architecture for optimal storage and retrieval performance with excellent write throughput.

Features

Powerful capabilities for reliable data storage

⚡

Async Networking with Tokio

Built on Tokio for high-performance asynchronous networking, enabling efficient handling of concurrent connections.

📝

Memtable with Skip List

In-memory data structure using skip list for fast writes and efficient range queries before data is flushed to disk.

🔄

Minor Compaction

Automatically merges smaller SSTables to optimize read performance and reduce storage fragmentation.

📦

Major Compaction

Full-scale compaction process that reorganizes all data levels for optimal storage efficiency and query performance.

Upcoming 🗳️

Raft Consensus

Planned support for distributed consensus using the Raft protocol, enabling high availability and fault tolerance.
