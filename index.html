MirDB

A persistent key-value store with memcached protocol compatibility

Built with Rust for performance and reliability. Drop-in replacement for memcached with data persistence using LSM tree architecture.

Get Started View on GitHub

Persistent Storage

Unlike memcached, MirDB persists your data to disk using LSM tree architecture with SSTables. Your data survives restarts and crashes.

Memcached Compatible

Drop-in replacement using the standard memcached text protocol. Your existing memcached clients connect seamlessly without any code changes.

Written in Rust

Built with Rust for memory safety, performance, and reliability. Async I/O powered by Tokio for handling thousands of concurrent connections.

Key Features

Persistent Storage

Unlike memcached, MirDB persists data to disk using SSTables, ensuring your data survives restarts.

Memcached Compatible

Drop-in replacement using standard memcached text protocol. Your existing clients work out of the box.

Written in Rust

Memory safety, high performance, and modern async I/O with Tokio runtime.

LSM Tree Architecture

Log-Structured Merge-tree with configurable levels, automatic compaction, and write-ahead logging.

Quick Start

# Clone and build from source
git clone https://github.com/yetone/mirdb
cd mirdb
cargo build --release

# Run MirDB server
./target/release/mirdb

# Connect with any memcached client
telnet localhost 12333
set hello 0 0 5
world
STORED
get hello
VALUE hello 0 5
world
END

# Default configuration (TOML format)
addr = "0.0.0.0:12333"
max_level = 7
work_dir = "/tmp/mirdb"
sst_max_size = "100M"
mem_table_max_size = "4M"
block_size = "4K"
