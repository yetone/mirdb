MirDB

A persistent key-value store with memcached compatibility

Drop-in replacement for memcached with data that persists

Get Started View on GitHub

Key Features

Memcached Protocol

Use your existing memcached clients - no code changes required. Full compatibility with the standard memcached text protocol.

Persistent Storage

Data survives restarts with LSM tree architecture and write-ahead logging. Never lose your cached data again.

High Performance

Async I/O with Tokio, efficient skip list memtables, and intelligent compaction for blazing fast operations.

Quick Start

Terminal 
# Start MirDB server
mirdb -c config.toml

# Connect with any memcached client
telnet localhost 12333

# Store and retrieve data
set mykey 0 0 5
hello
STORED

get mykey
VALUE mykey 0 5
hello
END

Supported Commands

Command Description
SET Store a key-value pair
GET Retrieve a value by key
DELETE Remove a key-value pair
ADD Store only if key doesn't exist
REPLACE Store only if key exists
APPEND Append data to existing value
PREPEND Prepend data to existing value
INFO Get server information (MirDB specific)
MAJOR_COMPACTION Trigger major compaction (MirDB specific)

Configuration

MirDB uses a TOML configuration file. Here are the default values:

Parameter Default Description
addr 0.0.0.0:12333 Listen address
work_dir /tmp/mirdb Data directory
mem_table_max_size 4MB Memtable size before flush
sst_max_size 100MB Maximum SSTable file size
max_level 7 LSM tree levels
