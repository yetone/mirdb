MirDB

A Persistent Key-Value Store with Memcached Protocol

Get Started View on GitHub

Key Features

Memcached Compatible

Works with existing memcached clients out of the box. Use familiar commands like GET, SET, and DELETE.

Persistent Storage

Data survives restarts using SSTable storage. Your data is safe with write-ahead logging.

High Performance

LSM tree architecture with background compaction for optimal read and write performance.

Quick Start

Installation

Clone the repository and build with Cargo:

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

# Run the server
cargo run --release

The server will start listening on 0.0.0.0:12333 by default.

Usage Example

Connect using telnet or any memcached client:

# Connect to the server
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

# Delete the value
delete mykey
DELETED

Supported Commands

SET key flags exptime bytes Store a key-value pair
GET key Retrieve a value by key
DELETE key Remove a key-value pair
