Quick Start

Installation

cargo install mirdb-server

Usage Example

# Start the server
mirdb-server

# Connect with telnet or any memcached client
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END
