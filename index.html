MirDB

Persistent Key-Value Store with Memcached Protocol

Get Started View on GitHub

Quick Start

Get up and running with MirDB in minutes.

Installation

Terminal 
cargo install mirdb-server

Basic Usage

Terminal 
# Start the MirDB server
mirdb-server --config /etc/mirdb.toml

# Connect using any Memcached client
# Example with telnet:
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
