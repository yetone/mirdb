MirDB

A persistent key-value store with memcached protocol compatibility

Drop-in replacement for memcached with data persistence. Built with Rust for speed and reliability, using LSM tree architecture for efficient storage.

Get Started View on GitHub

Key Features

Memcached Compatible

Works with existing memcached clients. Supports SET, GET, DELETE, ADD, REPLACE, APPEND, and PREPEND commands.

Data Persistence

Unlike traditional memcached, your data survives restarts. SSTables and Write-Ahead Log ensure durability.

LSM Tree Architecture

Efficient write performance with background compaction. Multi-level storage optimization for fast reads.

Built with Rust

Tokio-based async networking for high performance. Memory safety guarantees without garbage collection.

Quick Start

Installation

cargo install mirdb-server

# Run the server
mirdb-server --config /path/to/config.toml

Usage

# Connect with any memcached client
import memcache
client = memcache.Client(['localhost:12333'])

# Store data
client.set('key', 'value')

# Retrieve data
value = client.get('key')
