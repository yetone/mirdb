MirDB

Persistent Key-Value Store with Memcached Protocol Support

Key Features

Discover what makes MirDB unique.

Memcached Protocol Compatible

Drop-in replacement for Memcached clients. Use your existing client libraries without any code changes.

Persistent Storage

Data survives server restarts via LSM Tree storage engine with Write-Ahead Logging for durability.

Built with Rust

High performance and memory safety guaranteed by Rust's ownership system and zero-cost abstractions.

High Performance

Skip-List memtable for fast in-memory operations and configurable compression for efficient storage.

Quick Start

Get started with MirDB in minutes.

Installation

Install MirDB by cloning the repository and building with Cargo.

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

Configuration

Create a mirdb.toml configuration file with the following settings:

[server]
address = "127.0.0.1:11211"
work_dir = "./data"
memtable_size = "64MB"
sstable_max_size = "256MB"

Basic Usage

Connect to MirDB using any memcache client:

import memcache

# Connect to MirDB
client = memcache.Client(['localhost:11211'])

# Set a key-value pair
client.set('key', 'value')

# Get the value
value = client.get('key')
print(value)  # Output: value

Supported Operations

MirDB supports the following Memcached commands:

  • GET - Retrieve the value for a given key
  • GETS - Retrieve the value with CAS token for a given key
  • SET - Store a key-value pair
  • ADD - Store a key-value pair only if the key doesn't exist
  • REPLACE - Replace an existing value for a given key
  • APPEND - Append data to an existing value
  • PREPEND - Prepend data to an existing value
  • DELETE - Delete a key-value pair
  • INFO - Get server information
  • MajorCompaction - Trigger a major compaction for SSTable optimization
