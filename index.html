Why MirDB?

Drop-in Memcached Compatibility

Use your existing memcached clients without any code changes. MirDB implements the standard memcached text protocol, making migration seamless and effortless.

Built-in Persistence

Unlike standard memcached, your data survives restarts. MirDB persists data to disk using SSTable-based storage with write-ahead logging for durability.

LSM Tree Architecture

Optimized for write-heavy workloads with a Log-Structured Merge-tree architecture. Automatic compaction keeps your storage efficient and queries fast.
