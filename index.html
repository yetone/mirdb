MirDB

A persistent key-value store with memcached protocol support

Drop-in memcached replacement with data persistence, powered by Rust and LSM tree architecture.

Get Started View on GitHub

Key Features

🔌

Memcached Compatible

Full memcached text protocol support. Use your existing memcached clients seamlessly without any code changes. Supports GET, SET, DELETE, ADD, REPLACE, APPEND, and PREPEND commands.

💾

Persistent Storage

Unlike standard memcached, your data survives restarts. MirDB persists data to disk using SSTables (Sorted String Tables) with write-ahead logging for durability.

🌳

LSM Tree Architecture

Built on Log-Structured Merge-tree architecture optimized for write-heavy workloads. Features automatic background compaction across 7 levels for efficient storage management.

🦀

Written in Rust

Memory-safe implementation with zero-cost abstractions. Enjoy high performance without sacrificing safety. Powered by Tokio for async I/O and Snappy compression.

Quick Start

1. Installation

Clone and build MirDB from source:

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build with Cargo
cargo build --release

# Run the server
./target/release/mirdb-server

2. Connect to MirDB

Connect using any memcached client or telnet. Default port is 12333.

# Connect to MirDB
telnet localhost 12333

3. Store Data (SET)

Use the SET command to store key-value pairs:

# SET command syntax: SET <key> <flags> <exptime> <bytes>
SET mykey 0 0 5
hello
STORED

4. Retrieve Data (GET)

Use the GET command to retrieve stored values:

# GET command syntax: GET <key>
GET mykey
VALUE mykey 0 5
hello
END
