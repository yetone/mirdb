MirDB

A persistent key-value store with Memcached protocol compatibility. Combine the simplicity of Memcached with the durability of disk-based storage.

View on GitHub View Documentation

Key Features

🔌

Memcached Protocol

Drop-in compatible with existing Memcached clients. Use your favorite language's memcached library.

💾

Persistent Storage

Data persisted to disk using SSTables. Never lose your cached data again.

🌳

LSM Tree Architecture

Log-structured merge-tree design for optimal write performance and efficient storage.

⚡

Async I/O with Tokio

Built on Rust's Tokio runtime for high-performance asynchronous operations.

Code Examples

MirDB uses the standard Memcached protocol. Here's how to perform basic SET and GET operations:

Memcached Protocol 
# Connect to MirDB server
telnet localhost 12333

# SET operation - store a value
set mykey 0 0 5
hello
STORED

# GET operation - retrieve a value
get mykey
VALUE mykey 0 5
hello
END

# SET with expiration (60 seconds)
set tempkey 0 60 9
temporary
STORED

# DELETE operation
delete mykey
DELETED

Quick Start

Installation

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

Usage

# Start the server
./target/release/mirdb-server

# Connect using any memcached client
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END

Default Configuration

  • Listen address: 0.0.0.0:12333
  • Work directory: /tmp/mirdb
  • Memtable max size: 4MB
  • SSTable max size: 100MB
