MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance, persistent key-value store that speaks the Memcached protocol. Built with Rust for safety and speed.

Get Started View Documentation

Key Features

Memcached Compatible

Use your existing Memcached clients and tools without any modifications. MirDB implements the Memcached protocol, making migration seamless and integration effortless.

Persistent Storage

Your data survives restarts with our durable SSTable format. Unlike traditional Memcached, MirDB persists data to disk, ensuring your cached data is never lost.

High Performance

Built on LSM tree architecture with skip list memtables for blazing fast read and write operations. Optimized compaction strategies keep performance consistent over time.

Supported Commands

SET

Store a key-value pair in the database. Creates a new entry or updates an existing one.

GET

Retrieve the value associated with one or more keys from the database.

DELETE

Remove a key-value pair from the database permanently.

ADD

Store a key-value pair only if the key does not already exist in the database.

REPLACE

Update an existing key-value pair. Fails if the key does not exist.

APPEND

Append data to the end of an existing value for the specified key.

PREPEND

Prepend data to the beginning of an existing value for the specified key.

Quick Start

1. Install MirDB

Install MirDB using Cargo, the Rust package manager:

Terminal 
cargo install mirdb-server

2. Configure MirDB

Create a configuration file to customize MirDB settings:

mirdb.toml 
# Network settings
addr = "0.0.0.0:12333"

# Storage settings
work_dir = "/var/lib/mirdb"
max_level = 7

# SSTable configuration
sst_max_size = "100M"
mem_table_max_size = "4M"
block_size = "4K"

3. Start the Server

Run MirDB with your configuration file:

Terminal 
mirdb-server -c mirdb.toml

4. Connect and Use

Connect using telnet or any Memcached client to interact with MirDB:

Terminal 
# Connect using telnet
telnet localhost 12333

# Store a value
set mykey 0 0 5
hello
STORED

# Retrieve the value
get mykey
VALUE mykey 0 5
hello
END
