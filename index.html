MirDB

Persistent Key-Value Store with Memcached Protocol

View on GitHub Learn More

Key Features

Combine the simplicity of memcached with the durability of persistent storage

🔌

Memcached Protocol

Drop-in compatibility with existing memcached clients allows you to use your favorite client library without any code changes to your application.

💾

Persistent Storage

Your data survives restarts using SSTable format ensuring you never lose your cache data due to server restarts or unexpected failures.

⚡

LSM Tree Architecture

Efficient write-heavy workloads with automatic background compaction optimized for high-throughput operations and maximum performance.

Quick Start

Get up and running in seconds

# Connect to MirDB (default port: 12333)
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

# Delete the key
delete mykey
DELETED

Supported Commands

Full memcached text protocol support

SET Store data
GET Retrieve data
GETS Get with CAS
DELETE Remove data
ADD Add if not exists
REPLACE Replace existing
APPEND Append to value
PREPEND Prepend to value

Default Configuration

Key parameters and their default values

Listen Address 0.0.0.0:12333
Max LSM Levels 7
SSTable Max Size 100MB
Memtable Max Size 4MB
Block Size 4KB
