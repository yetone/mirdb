MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance, persistent key-value store written in Rust. Drop-in replacement for Memcached with durable storage powered by LSM tree architecture.

Get Started View on GitHub

Key Features

Memcached Protocol Compatibility

Full compatibility with the Memcached text protocol. Use your existing Memcached clients without any code changes. Supports GET, SET, ADD, REPLACE, DELETE, and more.

Persistent Storage with SSTables

Unlike in-memory caches, MirDB persists your data to disk using SSTables (Sorted String Tables). Your data survives restarts and system failures with Write-Ahead Logging (WAL).

LSM Tree Architecture

Built on Log-Structured Merge-tree (LSM) architecture for optimal write performance. Data flows from WAL to Memtable to immutable SSTables with automatic minor and major compaction.

Async Networking with Tokio

High-performance asynchronous networking powered by Tokio runtime. Handle thousands of concurrent connections efficiently with Rust's zero-cost abstractions and memory safety.

Quick Start

1. Clone and Build

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

2. Run the Server

./target/release/mirdb-server

3. Connect with Any Memcached Client

# Using telnet
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello

# Get the value
get mykey
