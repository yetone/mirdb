MirDB

A High-Performance Persistent Key-Value Store

Memcached protocol compatible with LSM-tree architecture for durability. Built in Rust for maximum performance and reliability.

View on GitHub Read Documentation

Key Features

Memcached Protocol

Drop-in compatibility with existing Memcached clients. Supports get, set, delete, and more.

LSM-Tree Architecture

Optimized for write-heavy workloads with efficient reads through level-based compaction.

Write-Ahead Logging

Data durability with crash recovery. Never lose your data.

Skip List Memtable

Fast in-memory operations with O(log n) complexity.

Snappy Compression

Reduced storage footprint with fast compression and decompression.

Cuckoo Filter

Fast key existence checks without disk reads.

Quick Start

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

# Run the server
./target/release/mirdb-server
