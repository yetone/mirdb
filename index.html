MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance, persistent key-value store written in Rust that implements the Memcached protocol. Unlike standard memcached, MirDB persists your data to disk, ensuring durability across restarts.

Get Started View on GitHub

Key Features

Everything you need for a reliable, high-performance key-value store

Memcached Compatibility

A drop-in replacement for existing memcached clients. Connect using any standard memcached client library without changing your application code.

Persistent Storage

Your data survives restarts. MirDB persists data to disk using SSTable-based storage, ensuring your cached values are durable and never lost.

LSM Tree Architecture

Built on a Log-Structured Merge-tree for efficient write performance. Background compaction keeps storage optimized without impacting query latency.

Async Networking

Built on Tokio for high-performance async I/O. Handle thousands of concurrent connections efficiently with non-blocking network operations.

Getting Started

Start using MirDB in minutes

Terminal 
# Start MirDB server
mirdb -c /path/to/config.toml

# Connect with any memcached client
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
