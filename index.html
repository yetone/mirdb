MirDB

A Persistent Key-Value Store with Memcached Protocol

View on GitHub Get Started

Features

  • Memcached protocol compatibility
  • Persistent key-value storage
  • Skip-list based memtable
  • Minor and major compaction
  • Rust-based implementation

See It In Action

Watch how easy it is to use MirDB with standard Memcached commands. The demonstration shows basic set and get operations.

Quick Start
