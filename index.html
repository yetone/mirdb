Key Features

Discover what makes MirDB a powerful choice for your key-value storage needs.

Memcached Protocol

Drop-in replacement with a familiar API. Seamlessly integrate with existing Memcached clients and infrastructure.

Persistent Storage

LSM-tree based durability ensures your data survives restarts. Never lose your key-value pairs again.

High Performance

Skip list memtables enable blazing-fast read and write operations for optimal throughput.

Automatic Compaction

Minor and major compaction support keeps your storage optimized automatically.

Configurable

TOML-based configuration provides flexible customization for your specific needs.

Async I/O

Built on Tokio for efficient networking, handling thousands of concurrent connections with ease.

Quick Start

Get MirDB up and running in minutes.

Installation 
# Clone the repository
git clone https://github.com/yetone/mirdb

# Build with Cargo
cd mirdb && cargo build --release

# Run the server
./target/release/mirdb-server -c etc/mirdb.toml
Basic Operations 
# Set a value
set mykey 0 3600 5
hello

# Get a value
get mykey

# Delete a value
delete mykey
