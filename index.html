MirDB

Persistent Key-Value Store with Memcached Protocol

Get Started View on GitHub

Why MirDB?

Drop-in Memcached Compatibility

Use your existing memcached clients without any code changes. MirDB implements the standard memcached text protocol, making migration seamless and effortless.

Built-in Persistence

Unlike standard memcached, your data survives restarts. MirDB persists data to disk using SSTable-based storage with write-ahead logging for durability.

LSM Tree Architecture

Optimized for write-heavy workloads with a Log-Structured Merge-tree architecture. Automatic compaction keeps your storage efficient and queries fast.

Supported Commands

MirDB implements the memcached text protocol with additional administrative commands.

Storage Commands

  • SET - Store a key-value pair
  • ADD - Store only if key doesn't exist
  • REPLACE - Store only if key exists
  • APPEND - Append data to existing value
  • PREPEND - Prepend data to existing value

Retrieval Commands

  • GET - Retrieve one or more keys
  • GETS - Retrieve with CAS token

Deletion Commands

  • DELETE - Remove a key

MirDB-Specific Commands

  • INFO - Display database status and level information
  • MAJOR_COMPACTION - Trigger manual compaction

Getting Started

1 Installation

Clone the repository and build MirDB using Cargo:

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

# Run MirDB with the default configuration
./target/release/mirdb-server -c etc/mirdb.toml

2 Configuration

MirDB uses TOML configuration files. Here's an example configuration (etc/mirdb.toml):

addr = "0.0.0.0:12333"

max_level = 7
work_dir = "/tmp/mirdb"

sst_max_size = "100M"
mem_table_max_size = "4M"
mem_table_max_height = 32

imm_mem_table_max_count = 16

block_size = "4K"
block_restart_interval = 16

l0_compaction_trigger = 4

thread_sleep_ms = 500

3 Basic Usage

Connect using any memcached client or tools like telnet or nc:

# Connect to MirDB
telnet localhost 12333

# Or using netcat
nc localhost 12333

# Store a value
set mykey 0 0 5
hello
STORED

# Retrieve the value
get mykey
VALUE mykey 0 5
hello
END

# Delete a key
delete mykey
DELETED

4 Supported Commands

MirDB supports the following memcached commands:

  • Storage: SET, ADD, REPLACE, APPEND, PREPEND
  • Retrieval: GET, GETS
  • Deletion: DELETE
  • MirDB-specific: INFO, MAJOR_COMPACTION
