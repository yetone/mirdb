MirDB

Persistent Key-Value Store with Memcached Protocol

A drop-in replacement for memcached that persists your data to disk. Built with Rust and powered by LSM tree architecture, MirDB combines the simplicity of the memcached protocol with durable persistent storage.

Get Started View on GitHub

Key Features

Memcached Compatibility

Works with existing memcached clients. No code changes required for basic operations like SET, GET, and DELETE.

Persistent Storage

Unlike memcached, your data survives restarts. Data is stored in SSTables for durability.

LSM Tree Architecture

Efficient write performance with background compaction. Perfect for write-heavy workloads.

Built with Rust

Memory-safe and high-performance. Powered by Tokio for async networking.

Getting Started

# Start MirDB server
mirdb -c /path/to/config.toml

# Connect with any memcached client
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END

Default Configuration

  • Listen address: 0.0.0.0:12333
  • Max LSM levels: 7
  • Work directory: /tmp/mirdb
  • SSTable max size: 100MB
  • Memtable max size: 4MB

Supported Commands

Storage

SET, ADD, REPLACE, APPEND, PREPEND

Retrieval

GET, GETS

Deletion

DELETE

MirDB-Specific

INFO, MAJOR_COMPACTION
