MirDB

A Persistent Key-Value Store with Memcached Protocol

Get Started

Features

Memcached Protocol

Drop-in replacement for memcached clients. Use your existing memcached-compatible libraries and tools with zero code changes.

Persistent Storage

Your data survives restarts. Unlike traditional memcached, MirDB persists data to disk ensuring durability without sacrificing performance.

LSM Tree Architecture

Built on Log-Structured Merge-tree for efficient write-heavy workloads. Optimized for high throughput with automatic compaction.

Quick Start

Installation

cargo install mirdb-server

Usage Example

# Start the server
mirdb-server

# Connect with telnet or any memcached client
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END
