MirDB

Persistent Key-Value Store with Memcached Protocol

MirDB is a persistent key-value store written in Rust that implements the Memcached protocol. Unlike traditional memcached, MirDB persists your data to disk using an LSM tree architecture, giving you the familiar memcached interface with the durability you need.

Get Started View on GitHub

Key Features

Memcached Compatible

Drop-in replacement using the standard memcached protocol. Connect using any standard memcached client.

Persistent Storage

Data survives restarts with SSTable-based storage on disk. Your data is safely persisted.

High Performance

LSM tree architecture with async I/O built on Tokio for high-performance networking.

Code Examples

Get started with MirDB using any standard memcached client. Here's how easy it is:

Connect to MirDB 
import memcache

# Connect to MirDB server
mc = memcache.Client(['127.0.0.1:12333'])
Store Data with SET 
# Store a value
mc.set('user:1', 'John Doe')

# Store with expiration (60 seconds)
mc.set('session:abc123', 'user_data', time=60)
Retrieve Data with GET 
# Retrieve a value
user = mc.get('user:1')
print(user)  # Output: John Doe

# Delete a value
mc.delete('user:1')

Getting Started

Installation 
# Clone and build from source
git clone https://github.com/yetone/mirdb
cd mirdb
cargo build --release

# Run with configuration
./target/release/mirdb -c etc/mirdb.toml

For more details, see the full documentation on GitHub.
