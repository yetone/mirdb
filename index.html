Key Features

Tokio Async Runtime

High-performance asynchronous I/O powered by Tokio, enabling thousands of concurrent connections with minimal overhead.

Memcached Protocol

Drop-in compatibility with existing tools and libraries. Use any memcached client without code changes.

SkipList Memtable

Efficient in-memory data structure using skip lists for fast writes and ordered range queries.

Compaction

Minor and major compaction for storage optimization, reclaiming space and improving read performance over time.
