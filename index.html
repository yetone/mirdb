MirDB

A Persistent Key-Value Store with Memcached Protocol

MirDB is a high-performance, persistent key-value store written in Rust. It implements the Memcached protocol, allowing seamless integration with existing memcached clients while providing durable disk-based storage.

View on GitHub Learn More

Key Features

Memcached Compatible

Full compatibility with the Memcached text protocol. Use your existing memcached clients seamlessly without any code changes. Supports GET, SET, DELETE, ADD, REPLACE, APPEND, and PREPEND commands.

Persistent Storage

Unlike traditional memcached, your data survives restarts. MirDB uses SSTable-based storage with Write-Ahead Logging (WAL) to ensure data durability and crash recovery.

LSM Tree Architecture

Built on a Log-Structured Merge-tree architecture with Tokio async I/O for high performance. Features memtables with skip lists, multi-level compaction, and efficient read/write paths.

Quick Start

bash 
# Start MirDB server
mirdb -c /path/to/config.toml

# Connect with any memcached client
$ telnet localhost 12333
> set mykey 0 0 5
> hello
STORED
> get mykey
VALUE mykey 0 5
hello
END
