What is MirDB?

MirDB is a persistent key-value store written in Rust that implements the Memcached protocol. It combines the simplicity of memcached with durable data persistence using SSTables and an LSM tree architecture. Built on Tokio's async runtime with a skip list memtable, MirDB delivers high-performance storage without sacrificing the familiar memcached experience.

Key Features

Tokio Async Runtime

High-performance asynchronous I/O powered by Tokio, enabling thousands of concurrent connections with minimal overhead.

Memcached Protocol

Drop-in compatibility with existing tools and libraries. Use any memcached client without code changes.

SkipList Memtable

Efficient in-memory data structure using skip lists for fast writes and ordered range queries.

Compaction

Minor and major compaction for storage optimization, reclaiming space and improving read performance over time.

Quick Start

MirDB speaks the memcached protocol. Connect with any memcached client and start storing data persistently.

mirdb-example.sh 
# Connect to MirDB with telnet
$ telnet localhost 11211

# Store a value (SET)
> set mykey 0 0 5
> hello
STORED

# Retrieve a value (GET)
> get mykey
VALUE mykey 0 5
hello
END

# Delete a value (DELETE)
> delete mykey
DELETED
