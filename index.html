MirDB

A Persistent Key-Value Store with Memcached Protocol

Get Started Learn More

Key Features

MirDB combines the simplicity of Memcached with the durability of persistent storage.

Memcached Protocol

Seamlessly integrate with existing memcached clients using Tokio for high-performance async I/O. Drop-in replacement for your current cache layer.

Skiplist Memtable

Efficient in-memory data structure using a skiplist-based memtable for fast read and write operations with O(log n) complexity.

Minor Compaction

Automatic minor compaction flushes memtable to SSTable files, ensuring data durability while maintaining high write throughput.

Major Compaction

Background major compaction merges and optimizes SSTable files, reducing storage overhead and improving read performance over time.

Quick Start

Getting started with MirDB is simple. Use any memcached client you're already familiar with. 

# Connect using any memcached client
telnet localhost 11211

# Set a key-value pair
set mykey 0 0 5
hello
STORED

# Retrieve the value
get mykey
VALUE mykey 0 5
hello
END

It's just like using memcached — drop-in compatible with your existing memcached clients, but with persistent storage that survives restarts.
