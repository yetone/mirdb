MirDB

Persistent Key-Value Store with Memcached Protocol

View on GitHub Get Started View Features

Key Features

Persistent Storage

Data persists to disk with LSM-tree architecture and SSTable format, ensuring durability and reliability.

Memcached Protocol

Fully compatible with the standard Memcached protocol, making integration seamless for existing applications.

Skiplist Memtable

High-performance memtable implementation using skiplist data structure for fast in-memory operations.

Compaction Support

Both minor and major compaction strategies to optimize storage and read performance over time.

Usage

MirDB works seamlessly with the standard memcached protocol:

# Start MirDB server
./mirdb-server

# Connect using any memcached client
# Set a key-value pair
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

Getting Started

1

Clone the Repository

git clone https://github.com/yetone/mirdb.git
cd mirdb
2

Build the Project

cargo build --release
3

Run the Server

./target/release/mirdb-server
4

Start Using MirDB

Connect using any memcached-compatible client and start storing data!
