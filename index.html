Quick Start

1. Start the MirDB Server

Run the MirDB server using cargo:

# Build and run the server
cargo run --release --bin mirdb-server

# Or with custom config
cargo run --release --bin mirdb-server -- -c etc/mirdb.toml

The server listens on 0.0.0.0:12333 by default.

2. Connect with a Memcached Client

Use telnet or any memcached-compatible client:

telnet localhost 12333

3. Set a Key-Value Pair

Store data using the set command:

# Format: set <key> <flags> <ttl> <bytes>
set mykey 0 0 5
hello
# Server responds: STORED

This sets the key mykey with value hello (5 bytes), no expiration.

4. Retrieve the Value

Get the stored value using the get command:

# Format: get <key>
get mykey
# Server responds:
# VALUE mykey 0 5
# hello
# END

Data Persistence

Unlike memcached, your data persists! Restart the server and your keys are still there.

# Restart the server
# Then connect again and retrieve your data
get mykey
# Value is still there: hello

MirDB vs Memcached

Feature MirDB Memcached
Data Storage Persistent (SSTables) In-memory only
Storage Engine LSM Tree Hash Table
On Restart Data preserved Data lost
Protocol Memcached compatible Memcached
