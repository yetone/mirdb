MirDB

Persistent Key-Value Store with Memcached Compatibility

MirDB combines the simplicity of memcached's protocol with the reliability of persistent storage. Built with Rust for safety and performance, MirDB uses an LSM-tree architecture to deliver fast writes while ensuring your data survives restarts. Drop-in replacement for memcached with data durability.

Quick Start

Get MirDB running in minutes with these simple steps.

  1. Prerequisites

    MirDB is built with Rust. Make sure you have Rust and Cargo installed. If you don't have Rust installed, get it from rustup.rs or run the following command: 

    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

  2. Clone and Build

    Clone the MirDB repository and build the project: 

    # Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

  3. Start the Server

    Run MirDB with the default configuration. The server will listen on port 12333: 

    # Start MirDB server
cargo run --release

# Or run with a custom config file
cargo run --release -- -c /path/to/config.toml

  4. Connect and Test

    Use any memcached client to connect. Here's a quick test using telnet: 

    # Connect to MirDB
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

Configuration

MirDB uses TOML configuration files for easy customization. Configure network settings, storage parameters, and performance tuning options.

Default Configuration Values

Parameter Default Value Description
addr 0.0.0.0:12333 Listen address and port
work_dir /tmp/mirdb Data directory path
max_level 7 Maximum LSM tree levels
mem_table_max_size 4MB Max memtable size before flush
sst_max_size 100MB Max SSTable file size
block_size 4KB Data block size
l0_compaction_trigger 4 Level 0 files before compaction

Configuration Example

Create a custom configuration file (e.g., mirdb.toml) to customize MirDB settings:

# Network settings
addr = "0.0.0.0:12333"

# Storage settings
max_level = 7
work_dir = "/var/lib/mirdb"

# Memory and SSTable settings
sst_max_size = "100M"
mem_table_max_size = "4M"
mem_table_max_height = 32

# Block settings
block_size = "4K"
block_restart_interval = 16

# Compaction settings
l0_compaction_trigger = 4

Run MirDB with your custom configuration:

mirdb -c /path/to/mirdb.toml
