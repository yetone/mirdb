Why Choose MirDB?

Three key benefits that set MirDB apart

🔌

Memcached Protocol Support

Drop-in replacement for memcached with full protocol compatibility. Use your existing memcached clients and code with zero modifications required.

💾

Persistence

Your data survives restarts with built-in durability. Unlike traditional memcached, MirDB ensures your cached data is never lost unexpectedly.

🌲

LSM Tree Architecture

Built on efficient Log-Structured Merge Tree architecture for optimal storage and retrieval performance with excellent write throughput.

Features

Powerful capabilities for reliable data storage

⚡

Async Networking with Tokio

Built on Tokio for high-performance asynchronous networking, enabling efficient handling of concurrent connections.

📝

Memtable with Skip List

In-memory data structure using skip list for fast writes and efficient range queries before data is flushed to disk.

🔄

Minor Compaction

Automatically merges smaller SSTables to optimize read performance and reduce storage fragmentation.

📦

Major Compaction

Full-scale compaction process that reorganizes all data levels for optimal storage efficiency and query performance.

Upcoming 🗳️

Raft Consensus

Planned support for distributed consensus using the Raft protocol, enabling high availability and fault tolerance.

Supported Commands

MirDB implements the memcached text protocol with additional MirDB-specific commands

Storage Commands

Commands for writing and modifying data

  • SET - Store a key-value pair
  • ADD - Store only if key doesn't exist
  • REPLACE - Store only if key exists
  • APPEND - Append data to existing value
  • PREPEND - Prepend data to existing value

Retrieval Commands

Commands for reading data

  • GET - Retrieve one or more keys
  • GETS - Retrieve with CAS token

Deletion Commands

Commands for removing data

  • DELETE - Remove a key from the store

MirDB-Specific Commands

Custom commands unique to MirDB

  • INFO - Display database status and level information
  • MAJOR_COMPACTION - Trigger manual compaction

Quick Start

Get up and running with MirDB in minutes

1 Clone and Build

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

2 Start the Server

# Run MirDB server
./target/release/mirdb-server

# Or with custom config
./target/release/mirdb-server -c etc/mirdb.toml

3 Connect and Use

# Connect using any memcached client
telnet localhost 12333

# SET a value
set mykey 0 0 5
hello
STORED

# GET the value
get mykey
VALUE mykey 0 5
hello
END

# DELETE the key
delete mykey
DELETED
