MirDB

A Persistent Key-Value Store with Memcached Protocol

View on GitHub Get Started

Features

Memcached Compatible

Drop-in replacement for memcached with full protocol support.

Persistent Storage

Data persists across restarts with SSTable-based storage.

LSM Tree Architecture

High-performance writes with efficient compaction.

Usage

# Start MirDB server
cargo run --release

# Connect using any memcached client
telnet localhost 11211

Architecture

MirDB uses a Log-Structured Merge-tree (LSM-tree) architecture for efficient write performance and durable storage.

Roadmap

  • Basic memcached protocol support
  • SSTable persistence
  • Compaction strategies
  • Clustering support
