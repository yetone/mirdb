MirDB

Persistent Key-Value Storage with Memcached Compatibility

A high-performance, persistent key-value store that speaks the memcached protocol. Drop-in replacement for memcached with data that survives restarts.

Get Started View on GitHub

Quick Start

Get up and running with MirDB in minutes.

Installation

Install MirDB using Cargo or build from source:

Using Cargo

cargo install mirdb

Build from Source

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

Usage Examples

MirDB uses the memcached protocol. Connect using any memcached client or telnet:

Start the Server

mirdb --listen 127.0.0.1:12333

Store Data with SET

Store a value with an expiration time (0 = no expiration):

SET mykey 0 0 5
hello
STORED

Retrieve Data with GET

Retrieve a previously stored value:

GET mykey
VALUE mykey 0 5
hello
END
