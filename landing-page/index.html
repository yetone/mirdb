Why MirDB?

Persistent Storage

Your data survives restarts

Memcached Protocol

Drop-in replacement, no code changes

LSM-Tree Architecture

Optimized for write-heavy workloads

Minor/Major Compaction

Automatic storage optimization

Rust-Powered

Memory safety and performance

Async I/O

Built on Tokio for scalability

Simple as Memcached

# Start MirDB server
mirdb-server --port 11211

# Use any Memcached client
telnet localhost 11211
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END

How It Works

graph TD A[Client] -->|Write| B[Memtable] B --> C[WAL] B -->|Flush| D[SSTable] A -->|Read| B A -->|Read| D D -->|Compaction| D

Memtable

In-memory skip list for fast writes

WAL

Write-ahead log for durability

SSTable

Sorted string tables on disk

Compaction

Background storage optimization

Get Started in Minutes

1. Install MirDB

cargo install mirdb-server

2. Start the Server

mirdb-server --port 11211 --data-dir ./data

3. Connect with Any Memcached Client

// Python example
import pymemcache
client = pymemcache.Client(('localhost', 11211))
client.set('key', 'value')
print(client.get('key'))
