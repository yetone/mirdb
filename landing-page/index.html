MirDB

A Persistent Key-Value Store with Memcached Protocol

A high-performance, drop-in memcached replacement with persistence guarantees. Use your existing memcached clients without modification while gaining durable storage powered by LSM-tree architecture.

Get Started View on GitHub

Features

Memcached Compatible

Existing memcached clients work without modification. Use your favorite language's memcached library and connect to MirDB seamlessly. Supports get, set, delete, and more standard commands.

Persistent Storage

Built on LSM-tree architecture with SSTable-based storage. Your data survives restarts with write-ahead logging for durability. No more cold cache problems.

High Performance

Powered by skip-list memtable implementation for fast in-memory operations. Intelligent compaction strategies optimize read and write performance automatically.

Configurable

Flexible configuration options for various deployment scenarios. Tune memtable size, SSTable limits, compaction triggers, and more via simple TOML configuration.
