MirDB

Persistent Memcached-Compatible Key-Value Store in Rust

A high-performance, persistent key-value store that speaks the Memcached protocol. Built with Rust and powered by LSM tree architecture for durability and speed.

Get Started View Documentation

Why MirDB?

Memcached Protocol Compatible

Drop-in replacement for Memcached. Use your existing Memcached clients and libraries without any code changes. Full support for SET, GET, DELETE, ADD, REPLACE, and more commands.

Persistent Storage

Unlike standard Memcached, MirDB persists your data to disk using SSTables (Sorted String Tables). Your data survives restarts and system failures for true durability.

LSM Tree Architecture

Built on a Log-Structured Merge-tree storage engine for optimal write performance. Features skip-list memtables, multi-level compaction, and efficient read paths.

Quick Start

MirDB uses the standard Memcached text protocol. Connect with any Memcached client or use telnet to get started.

Store Data with SET

SET mykey 0 0 11
Hello World
STORED

Store a key-value pair. Parameters: key, flags, TTL (0=no expiration), byte count.

Retrieve Data with GET

GET mykey
VALUE mykey 0 11
Hello World
END

Retrieve one or more keys. Returns the value along with metadata.

Remove Data with DELETE

DELETE mykey
DELETED

Remove a key from the store. Returns DELETED on success, NOT_FOUND if key doesn't exist.

Supported Commands

SET Store a key-value pair
GET Retrieve value by key
DELETE Remove a key
ADD Store only if key doesn't exist
REPLACE Store only if key exists
APPEND Append data to existing value
PREPEND Prepend data to existing value
GETS Retrieve with CAS token
