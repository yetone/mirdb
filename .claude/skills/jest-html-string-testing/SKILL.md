Use this skill when testing static HTML files with Jest and encountering ESM module compatibility issues with JSDOM.

## When to Use

- Testing static HTML page structure
- Verifying HTML contains expected elements, attributes, or content
- Avoiding JSDOM ESM compatibility errors
- Unit testing for static site generators or HTML-first projects
