MirDB

Persistent Key-Value Storage with Memcached Compatibility

A high-performance key-value store that combines the simplicity of memcached with the durability of persistent storage. Your data survives restarts.

Get Started View on GitHub

Key Features

Memcached Protocol Compatible

Drop-in replacement for existing memcached clients. Full text protocol support allows seamless migration without code changes.

Persistent Storage

Data survives restarts using SSTables (Sorted String Tables). Unlike memcached, your cached data is durable and persisted to disk.

High Performance

Built on LSM-tree architecture with Tokio async I/O for maximum throughput. Efficient write-optimized storage with fast reads.

Configurable

Extensive configuration options for tuning performance. Customize memtable size, SSTable limits, block size, and compaction settings.

Get Started

Installation

cargo install mirdb

Or build from source:

git clone https://github.com/example/mirdb.git
cd mirdb
cargo build --release

Quick Start

# Start the server
./mirdb-server

# Connect with any memcached client
echo "set mykey 0 0 5\r\nhello\r\n" | nc localhost 12333
echo "get mykey\r\n" | nc localhost 12333
