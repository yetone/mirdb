MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance, persistent key-value store written in Rust. MirDB combines memcached protocol compatibility with durable storage using LSM-tree architecture.

Get Started View on GitHub

Key Features

Built for performance, designed for durability

🚀

Memcached Protocol Compatible

Full compatibility with the memcached text protocol. Use your existing memcached clients without any modifications. Supports SET, GET, DELETE, ADD, REPLACE, APPEND, and PREPEND commands.

💾

Persistent Storage with SSTables

Unlike traditional memcached, MirDB persists your data to disk using SSTables (Sorted String Tables). Your data survives restarts and system failures with automatic recovery.

📈

LSM-Tree Architecture

Built on a Log-Structured Merge-tree architecture for optimal write performance. Data flows through memtable to multi-level SSTables with configurable compaction strategies.

⚡

High Performance with Rust

Written in Rust for maximum performance and memory safety. Leverages Tokio for async I/O operations, delivering low-latency responses with minimal resource overhead.

🛠

Write-Ahead Log (WAL)

Every write is first logged to a Write-Ahead Log before being applied, ensuring durability and crash recovery. Data is never lost even during unexpected shutdowns.

🔧

Configurable Compaction

Fine-tune compaction behavior with configurable triggers and thresholds. Supports both minor compaction (memtable to SSTable) and major compaction (level-to-level SSTable merging).

📑

Skip List Memtable

In-memory data is stored in an efficient skip list data structure, providing O(log n) insert and lookup operations. Optimized for high-throughput write workloads.

Supported Memcached Commands

MirDB supports the following memcached text protocol commands:

SET

Store a key-value pair with optional TTL

GET

Retrieve the value for one or more keys

DELETE

Remove a key from the store

ADD

Store only if the key does not exist

REPLACE

Store only if the key already exists

APPEND

Append data to an existing value

PREPEND

Prepend data to an existing value

Usage Example

Connect with any memcached client. Here's an example using Python:

Python 
from pymemcache.client import base

# Connect to MirDB
client = base.Client(('localhost', 12333))

# Store a value
client.set('mykey', 'Hello, MirDB!')

# Retrieve the value
result = client.get('mykey')
print(result)  # b'Hello, MirDB!'

# Delete the key
client.delete('mykey')

Getting Started

1. Build from Source

git clone https://github.com/example/mirdb.git
cd mirdb
cargo build --release

2. Run MirDB

./target/release/mirdb-server

3. Connect with Memcached Client

# Default port: 12333
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
