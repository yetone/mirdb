Key Features

Everything you need for a reliable, high-performance key-value store.

Memcached Protocol

Full compatibility with the Memcached protocol. Use your existing clients and tools without any code changes.

LSM Tree Persistence

Durable storage powered by Log-Structured Merge trees. Your data survives restarts and crashes with efficient write performance.

TTL Support

Set expiration times on your keys. Automatic cleanup of expired entries keeps your storage lean and efficient.

Fault Tolerance

Write-Ahead Logging (WAL) ensures crash recovery. Your data is protected against unexpected failures and power outages.

Automatic Compaction

Background compaction optimizes storage by merging and cleaning up data files. Maintains performance over time.

High Performance

Optimized for speed with in-memory caching and efficient disk I/O. Sub-millisecond read latencies at scale.
