MirDB

A Persistent Key-Value Store with Memcached Protocol

Drop-in memcached replacement with disk persistence. Built with Rust.

Get Started View on GitHub

Features

Everything you need for a high-performance persistent cache

Memcached Protocol

Drop-in replacement for memcached. Use existing clients and tools without any code changes.

Persistence (SSTables)

Durable storage with SSTable-based persistence. Your data survives restarts and crashes.

LSM Tree Architecture

Log-structured merge tree design optimized for write-heavy workloads with efficient compaction.

Rust Implementation

Built with Rust for memory safety, zero-cost abstractions, and blazing-fast performance.

Quick Start

Get up and running with MirDB in minutes

1 Install MirDB

bash 
# Install from cargo
cargo install mirdb

2 Start Using MirDB

bash 
# Start the server
mirdb --listen 0.0.0.0:12333

# Set a value (using telnet or any memcached client)
set mykey 0 0 5
hello

# Get the value
get mykey

Architecture

LSM Tree (Log-Structured Merge Tree) storage engine for high-performance persistent storage

WAL
Memtable

Read Path

Memtable
SSTable
WAL

Write-Ahead Log

All writes are first appended to the WAL (Write-Ahead Log) before updating the Memtable. This ensures durability - even if the system crashes, data can be recovered from the WAL on restart.

Memtable

Memtable

An in-memory data structure (skip list) that stores recent writes. When the Memtable reaches its size threshold, it becomes immutable and is flushed to disk as an SSTable.

SSTable

Sorted String Table

Immutable, sorted files on disk containing key-value pairs. SSTables are organized into levels (L0, L1, etc.) and periodically compacted to merge overlapping data and reclaim space.

Protocol Reference

Full memcached protocol compatibility with additional MirDB-specific commands

Command Description Type
set Store a key-value pair, overwriting if it exists Standard
get Retrieve one or more keys from the database Standard
delete Remove a key and its associated value Standard
add Store only if the key does not already exist Standard
replace Store only if the key already exists Standard
append Append data to an existing value Standard
prepend Prepend data to an existing value Standard
gets Retrieve keys with CAS (Check-And-Set) token for optimistic locking Standard
info Display database status, statistics, and configuration MirDB
major_compaction Trigger manual SSTable compaction across all levels MirDB

Note: Commands marked as MirDB are extensions specific to MirDB and are not part of the standard memcached protocol.
