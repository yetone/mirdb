MirDB

A Persistent Key-Value Store with Memcached Protocol

Fast, reliable, and painless as using Memcached

View on GitHub Read Documentation

Key Features

🔌

Memcached Protocol

Drop-in compatibility with existing Memcached clients. No code changes required.

📈

Skip-list Memtable

Efficient in-memory data structure for blazing fast writes and lookups.

🛠

Automatic Compaction

Minor and major compaction for optimized storage and consistent performance.

⚡

Async Runtime

Built on Tokio for high-performance async I/O and excellent scalability.

💾

Persistent Storage

LSM-tree based architecture ensures data durability and crash recovery.

Quick Example

Use any Memcached client to interact with MirDB:

# Connect to MirDB using telnet
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

Quick Start

1

Clone the repository

git clone https://github.com/jksgit/mirdb.git
cd mirdb
2

Build with Cargo

cargo build --release
3

Run MirDB

./target/release/mirdb
