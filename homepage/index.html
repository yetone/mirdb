MirDB

A Persistent Key-Value Store with Memcached protocol support, written in Rust

Get Started Documentation

Features

Memcached Protocol

Drop-in compatible with existing Memcached clients. Use your favorite language and library to connect.

LSM-Tree Storage

Efficient log-structured merge-tree engine for high-performance persistent storage with optimized write paths.

Write-Ahead Logging

Durable writes with crash recovery support. Your data is safe even during unexpected shutdowns.

Auto Compaction

Background minor and major compaction keeps storage optimized without manual intervention.

LRU Block Cache

In-memory caching for fast repeated reads with intelligent least-recently-used eviction.

Snappy Compression

Efficient data compression reduces storage footprint while maintaining fast read/write speeds.

Cuckoo Filter

Fast probabilistic key existence checks to minimize unnecessary disk reads.

Rust Performance

Memory-safe systems programming with zero-cost abstractions for maximum performance and reliability.
