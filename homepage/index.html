MirDB

A persistent key-value store with Memcached protocol compatibility, written in Rust

Key Features

Memcached Compatible

Drop-in replacement supporting the standard Memcached text protocol. Use your existing clients and tools.

Persistent Storage

LSM-tree architecture with SSTable files ensures your data survives restarts.

High Performance

Skip list memtables, LRU block cache, and Cuckoo filters for blazing fast operations.

Durable

Write-ahead logging guarantees crash recovery and data integrity.

Efficient

Snappy compression and automatic compaction keep storage optimized.

Written in Rust

Memory-safe, concurrent, and fast. Built with Tokio for async I/O.

Architecture Overview

MirDB uses a Log-Structured Merge-tree (LSM-tree) architecture that provides excellent write performance while maintaining efficient reads. LSM-trees optimize for write-heavy workloads by buffering writes in memory and periodically flushing them to disk in sorted order, reducing random I/O and enabling efficient compaction.

Write Path

Writes flow through: Client → WAL → Memtable → SSTable. Data is first logged to the Write-Ahead Log for durability, then inserted into the in-memory Memtable (skip list). When the Memtable reaches its size limit, it's flushed to disk as an SSTable file.

Read Path

Reads flow through: Client → Memtable → Immutable List → SSTable Levels. The most recent data is checked first in the active Memtable, then the immutable Memtable list, and finally the SSTable files organized in levels (L0 to max level).

Getting Started

Installation

# Clone the repository
git clone https://github.com/yetone/mirdb.git

# Build the server
cd mirdb
cargo build --release

# Run MirDB
./target/release/mirdb-server

Configuration

MirDB uses TOML configuration files. Create a config file at etc/mirdb.toml:

# Server configuration
addr = "0.0.0.0:12333"

# Storage settings
work_dir = "/tmp/mirdb"
max_level = 7

# Memory settings
mem_table_max_size = "4M"
mem_table_max_height = 32

# SSTable settings
sst_max_size = "100M"
block_size = "4K"

# Compaction settings
l0_compaction_trigger = 4

Start MirDB with your configuration file:

./target/release/mirdb-server -c /path/to/mirdb.toml

Basic Usage

Connect using any Memcached client. Here are examples using telnet:

# Connect to MirDB
telnet localhost 12333

# Set a value (key: mykey, flags: 0, ttl: 0, bytes: 5)
set mykey 0 0 5
hello
STORED

# Get the value back
get mykey
VALUE mykey 0 5
hello
END

# Delete the key
delete mykey
DELETED

You can also use any Memcached client library in your preferred language:

# Python example using pymemcache
from pymemcache.client import base

client = base.Client(('localhost', 12333))

# Set a value
client.set('user:1', 'John Doe')

# Get the value
result = client.get('user:1')
print(result)  # b'John Doe'

# Delete the key
client.delete('user:1')
