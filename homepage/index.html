MirDB

A Persistent Key-Value Store with Memcached protocol

View on GitHub Get Started

Usage

MirDB implements the Memcached text protocol, allowing you to use any Memcached client or connect directly via telnet.

Store a Value (SET)

The set command stores a key-value pair. The format is: set <key> <flags> <ttl> <bytes> followed by the value on the next line.

set mykey 0 0 5
value
STORED

This stores the value "value" (5 bytes) under the key "mykey" with no flags (0) and no expiration (0). The server responds with STORED on success.

Retrieve a Value (GET)

The get command retrieves one or more keys from the store.

get mykey
VALUE mykey 0 5
value
END

This retrieves the value for "mykey". The response includes the key name, flags, byte count, the actual value, and END to indicate completion.

Delete a Value (DELETE)

The delete command removes a key from the store.

delete mykey
DELETED

This removes "mykey" from the store. The server responds with DELETED on success, or NOT_FOUND if the key doesn't exist.

Connecting to MirDB

Connect using telnet or any Memcached-compatible client.

# Connect via telnet
telnet localhost 12333

# Or use a Memcached client library
# Python example:
# import pymemcache
# client = pymemcache.Client(('localhost', 12333))

MirDB listens on port 12333 by default. Any Memcached client can connect and use the standard commands.
