MirDB

Persistent Key-Value Store with Memcached Compatibility

A high-performance, persistent key-value store built in Rust. Get the familiarity of memcached with the reliability of persistent storage powered by LSM-tree architecture.

Get Started View on GitHub

Quick Start

# Clone and build MirDB
git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

# Run the server
./target/release/mirdb-server

# Connect using any memcached client
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END

Key Features

Memcached Protocol

Full compatibility with memcached text protocol. Use existing clients and tools without modification.

Persistent Storage

Unlike memcached, your data survives restarts. LSM-tree architecture ensures durability and efficient writes.

Write-Ahead Logging

Every write is logged before acknowledgment, ensuring no data loss even during unexpected shutdowns.

Async I/O with Tokio

Built on Rust's Tokio runtime for high-performance, non-blocking network I/O.

Background Compaction

Automatic background compaction keeps storage efficient without impacting query performance.

Built in Rust

Memory safety and performance without compromise. Zero-cost abstractions and fearless concurrency.
