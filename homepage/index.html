MirDB: A persistent key-value store with Memcached protocol.

Fast, reliable, and Rust-powered storage engine for your applications.

View on GitHub Get Started

Key Features

Memcached Protocol

Full Memcached protocol compatibility allows seamless integration with existing clients and tools. Use your favorite Memcached libraries.

Persistent Storage

Data persistence ensures durability across restarts. Your data is safely stored on disk with reliable write-ahead logging.

LSM Tree Architecture

Log-Structured Merge-tree provides excellent write performance and efficient storage utilization with background compaction.

Automatic Compaction

Both minor and major compaction run automatically to optimize storage and maintain query performance over time.

Usage Example

MirDB supports standard Memcached protocol commands. Here's how to interact with it:

Example Commands

# Connect to MirDB using telnet or any Memcached client
telnet localhost 11211

# SET a value
set mykey 0 0 5
hello
STORED

# GET a value
get mykey
VALUE mykey 0 5
hello
END

# DELETE a value
delete mykey
DELETED

# SET with expiration (60 seconds)
set tempkey 0 60 5
world
STORED

Get Started

Get MirDB running in just 3 simple steps.

1

Clone and Build

Clone the repository and build the project using Cargo.

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release
2

Run the Server

Start the MirDB server on the default port.

./target/release/mirdb-server
3

Connect and Use

Connect using any Memcached client or telnet.

telnet localhost 11211
set hello 0 0 5
world
get hello
