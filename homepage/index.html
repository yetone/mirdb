MirDB

Persistent Key-Value Store with Memcached Protocol

Get the simplicity of memcached with the durability of disk-backed storage. MirDB persists your data using an efficient LSM tree architecture while maintaining full compatibility with the memcached protocol.

Get Started View on GitHub

Key Features

Memcached Protocol

Drop-in compatibility with standard memcached text protocol. Use your existing clients seamlessly.

Data Persistence

Unlike memcached, MirDB persists data to disk. No more cold cache problems after restarts.

LSM Tree Architecture

Efficient storage engine optimized for write-heavy workloads with multi-level compaction.

Rust Performance

Written in Rust for memory safety and high performance without garbage collection pauses.

Quick Start

# Clone and build
git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

# Run the server
./target/release/mirdb-server

# Connect with any memcached client
telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END

Default Configuration

  • Port: 12333
  • Storage: /tmp/mirdb
  • Memtable Size: 4MB before flush
  • SSTable Size: Up to 100MB per file
  • LSM Levels: 7 levels
