MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance, persistent database that speaks Memcached. Built with Rust for reliability and speed.

Get Started View on GitHub

Key Features

Memcached Protocol

Connect using any standard Memcached client. Zero migration effort for existing applications. Full protocol compatibility means you can switch without changing your code.

Persistent Storage

Data survives restarts. SSTables provide durable, efficient disk storage. Never lose your cached data again with automatic persistence to disk.

LSM Tree Architecture

Optimized for write-heavy workloads with intelligent compaction strategies. The Log-Structured Merge-Tree design ensures consistent high performance at scale.

Rust Performance

Built with Tokio for async I/O. Safe, fast, and resource-efficient. Leverages Rust's memory safety guarantees without sacrificing speed.

Quick Start

Installation 
# Clone and build MirDB
git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

# Run the server
./target/release/mirdb-server

# Connect with any Memcached client
# Default address: 0.0.0.0:12333
Connect with Memcached Client (Python) 
from pymemcache.client import base

# Connect to MirDB using standard Memcached client
client = base.Client(('0.0.0.0', 12333))

# Set a value
client.set('key', 'value')

# Get the value
result = client.get('key')
print(result)  # b'value'

Default Configuration

Listen Address 0.0.0.0:12333
Work Directory /tmp/mirdb
Memtable Size 4MB
SSTable Size 100MB
Block Size 4KB
Max LSM Levels 7
