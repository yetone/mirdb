MirDB

Persistent Key-Value Store with Memcached Protocol

  • Memcached protocol compatible - use existing clients
  • Persistent storage via LSM tree architecture
  • Written in Rust for safety and performance
Get Started View on GitHub

Key Features

Memcached Compatible

Drop-in replacement for existing memcached clients. Fully implements the memcached text protocol, allowing seamless integration with your current infrastructure.

Persistent Storage

Unlike traditional memcached, MirDB persists data to disk using SSTable (Sorted String Table) storage. Your data survives restarts and system failures.

LSM Tree Architecture

Built on a Log-Structured Merge (LSM) tree architecture with efficient writes, background compaction, and optimized read paths across multiple storage levels.

Async Performance

Powered by Tokio for high-throughput asynchronous operations. Handle thousands of concurrent connections with minimal resource overhead.

Getting Started

1

Clone the Repository

git clone https://github.com/yetone/mirdb.git
cd mirdb
2

Build and Run

cargo build --release
./target/release/mirdb-server
3

Connect with Any Memcached Client

# Using telnet
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END
