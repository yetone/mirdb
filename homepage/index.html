MirDB: A persistent key-value store with Memcached protocol.

Fast, reliable, and Rust-powered storage engine for your applications.

Key Features

Memcached Protocol

Full Memcached protocol compatibility allows seamless integration with existing clients and tools. Use your favorite Memcached libraries.

Persistent Storage

Data persistence ensures durability across restarts. Your data is safely stored on disk with reliable write-ahead logging.

LSM Tree Architecture

Log-Structured Merge-tree provides excellent write performance and efficient storage utilization with background compaction.

Automatic Compaction

Both minor and major compaction run automatically to optimize storage and maintain query performance over time.
