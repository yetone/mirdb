MirDB

A Persistent Key-Value Store with Memcached Protocol

Get Started

Features

Memcached Protocol

Drop-in compatible with the Memcached protocol. Use your existing Memcached clients and libraries without any code changes.

Persistent Storage

Your data survives restarts. MirDB provides persistent storage so you never lose your cached data, combining the speed of in-memory caching with durability.

LSM Tree Architecture

Built on a Log-Structured Merge tree design with skip list memtable and efficient compaction for optimal write performance and storage efficiency.

Quick Start

MirDB is compatible with the Memcached protocol. Use your favorite Memcached client to connect and start storing data:

Shell 
# Connect to MirDB using telnet
telnet localhost 11211

# Store a value with SET command
set mykey 0 0 5
hello
STORED

# Retrieve the value with GET command
get mykey
VALUE mykey 0 5
hello
END

# Delete a key
delete mykey
DELETED

Or use any Memcached client library in your preferred language - Python, Node.js, Java, Go, and more!
