Key Features

Memcached Protocol

Full compatibility with the Memcached protocol, allowing seamless integration with existing Memcached clients and tools without any code changes.

Persistent Storage

Unlike traditional caches, MirDB provides durable data persistence, ensuring your data survives restarts and system failures.

LSM Tree Architecture

Built on a Log-Structured Merge tree design, optimizing for high write throughput while maintaining efficient read operations.
