MirDB

A high-performance, persistent key-value store with Memcached protocol compatibility

Built in Rust with an LSM-tree storage engine for durability and speed. Drop-in replacement for Memcached with persistent storage capabilities.

Get Started View on GitHub

Key Features

Memcached Compatible

Drop-in replacement supporting get, set, delete, and more standard Memcached commands.

Persistent Storage

LSM-tree architecture with SSTable files for durable data storage.

Write-Ahead Logging

Never lose data with WAL-based crash recovery.

High Performance

Skip list memtables and LRU block cache for fast operations.

Efficient Compression

Snappy compression reduces storage footprint.

Smart Filtering

Cuckoo filters minimize unnecessary disk reads.

Getting Started

Installation

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build with Cargo
cargo build --release

# Run the server
./target/release/mirdb-server

Quick Configuration

Create a configuration file at etc/mirdb.toml: 

# MirDB Configuration
addr = "0.0.0.0:12333"
work_dir = "/var/lib/mirdb"

# Memory settings
mem_table_max_size = "4M"
mem_table_max_height = 32

# Storage settings
sst_max_size = "100M"
block_size = "4K"

# LSM-tree settings
max_level = 7
l0_compaction_trigger = 4
