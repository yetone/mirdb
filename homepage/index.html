MirDB

A persistent key-value store with Memcached protocol support

Built in Rust for performance and reliability, using LSM tree architecture for efficient storage.

Get Started View on GitHub

Key Features

Memcached Protocol Compatibility

Fully compatible with the standard Memcached text protocol. Use your existing memcached clients seamlessly with MirDB.

Persistent Storage with SSTables

Unlike memcached, MirDB persists your data to disk using SSTables (Sorted String Tables) for durable storage that survives restarts.

LSM Tree Architecture

Log-Structured Merge tree design with memtables, immutable memtables, and multi-level SSTable compaction for optimized write performance.

Async Rust with Tokio

Built on Tokio's async runtime for high-performance, non-blocking I/O operations. Handle thousands of concurrent connections efficiently.

Getting Started

Installation

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build from source
cargo build --release

Basic Usage

# Start the server
./target/release/mirdb-server

# Connect using any memcached client
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello

# Get the value
get mykey
