About MirDB

MirDB is a persistent key-value store that speaks the Memcached protocol. Built from the ground up in Rust, it provides durability through LSM-tree storage while maintaining the simplicity and speed that developers expect from key-value stores.

Key Features

  • Memcached Protocol Compatibility

    Drop-in replacement for Memcached with full protocol support for GET, SET, DELETE, and more.

  • Persistent Storage with LSM Tree

    Data is durably stored using a Log-Structured Merge tree with SSTables and compaction.

  • Rust Implementation

    Written in Rust for memory safety, performance, and reliability without garbage collection overhead.

  • Async I/O with Tokio

    Leverages Tokio runtime for high-performance asynchronous I/O and concurrent request handling.

  • Skip-list Memtable

    Efficient in-memory data structure for fast writes and range queries.

  • SSTable Compaction

    Automatic background compaction for optimized reads and storage efficiency.

Quick Start

Get up and running with MirDB in minutes:

# Install MirDB
cargo install mirdb

# Start the MirDB server
mirdb-server

# Connect using any Memcached client
# Example with telnet:
telnet localhost 11211
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
