MirDB

A Persistent Key-Value Store implementing the Memcached protocol. Built with Rust and powered by an LSM-tree storage engine.

Get Started

Features

Powerful capabilities for modern applications

Persistent Storage

Data durability guaranteed with persistent storage on disk. Your data survives restarts and system failures.

Memcached Protocol

Drop-in compatibility with the Memcached protocol. Use existing clients and tools without modification.

LSM-tree Storage Engine

Log-Structured Merge-tree architecture optimized for write-heavy workloads with excellent read performance.

Skip-list Memtable

In-memory skip-list data structure providing O(log n) operations for fast lookups and ordered iteration.

Compaction Support

Automatic minor and major compaction to optimize storage and maintain query performance over time.

Built With

Powered by modern, battle-tested technologies

Rust

Systems programming language providing memory safety, fearless concurrency, and zero-cost abstractions.

Tokio

Asynchronous runtime for Rust enabling high-performance networking and concurrent I/O operations.

LSM-tree

Log-Structured Merge-tree storage engine optimized for write-intensive workloads with efficient compaction.

Memcached Protocol

Full compatibility with the Memcached text protocol for seamless integration with existing clients.

Quick Start

Get up and running with MirDB in minutes

1

Clone & Build

Clone the repository and build MirDB using Cargo.

# Clone the repository
git clone https://github.com/mirdb/mirdb.git
cd mirdb

# Build the project
cargo build --release
2

Start the Server

Launch MirDB with the default configuration.

# Run MirDB server
cargo run --release

# Server starts on port 11211 (Memcached default)
# Listening on 127.0.0.1:11211...
3

Basic Operations

Connect using any Memcached client and perform get/set operations.

# Connect using telnet or any Memcached client
telnet localhost 11211

# Set a key-value pair (format: set <key> <flags> <exptime> <bytes>)
set mykey 0 0 5
hello
STORED

# Get the value by key
get mykey
VALUE mykey 0 5
hello
END

# Delete a key
delete mykey
DELETED
