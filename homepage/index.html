Key Features

Built for performance, designed for simplicity

Memcached Protocol

Drop-in compatibility with existing Memcached clients. Use your favorite libraries and tools without any changes.

LSM Tree Storage

Log-Structured Merge-tree architecture optimized for high write throughput while maintaining efficient read operations.

Skip-List Memtable

In-memory skip-list structure for fast key-value lookups and efficient ordered iteration during flush operations.

Automatic Compaction

Background minor and major compaction processes to maintain optimal storage efficiency and read performance.

Crash Recovery

Write-ahead logging (WAL) ensures data durability. Recover seamlessly from unexpected shutdowns without data loss.

SSTable Format

Sorted String Tables provide efficient on-disk storage with bloom filters for fast negative lookups.
