MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance key-value database built with Rust, featuring LSM tree architecture and full Memcached protocol compatibility. Your data persists across restarts.

Get Started View Documentation

Key Features

Memcached Compatible

Use existing Memcached clients and tools. Full support for SET, GET, DELETE, ADD, REPLACE, APPEND, and PREPEND commands.

Persistent Storage

Unlike Memcached, MirDB persists your data to disk using SSTables. Your data survives server restarts.

High Performance

LSM tree architecture with skip list memtables, Write-Ahead Log (WAL) for durability, and efficient compaction.

Quick Start

1. Build from Source

git clone https://github.com/yetone/mirdb.git
cd mirdb
cargo build --release

2. Run MirDB

./target/release/mirdb-server

Default port: 12333

3. Connect with Telnet

telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END

Architecture Overview

MirDB uses an LSM (Log-Structured Merge) tree architecture for efficient writes and reliable data persistence.

Write Request
      │
      ▼
┌─────────────┐
│     WAL     │ ◄─── Write-Ahead Log (durability)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  Memtable   │ ◄─── In-memory skip list (fast writes)
└──────┬──────┘
       │ (when full)
       ▼
┌─────────────┐
│   SSTable   │ ◄─── Sorted String Table (persistent storage)
└─────────────┘

Write-Ahead Log (WAL)

The WAL provides durability by persisting every write operation to disk before acknowledging it. In case of a crash, MirDB can recover data by replaying the WAL, ensuring no committed data is lost.

Memtable

An in-memory data structure (skip list) that stores recent writes for fast access. When the Memtable reaches its size threshold (default 4MB), it becomes immutable and is flushed to disk as an SSTable.

SSTable

Sorted String Tables are immutable files stored on disk containing sorted key-value pairs. SSTables use block compression, cuckoo filters for fast lookups, and are organized into levels for efficient compaction.
