MirDB: A Persistent Key-Value Store with Memcached Protocol

Drop-in replacement for memcached with persistent storage. Built with Rust for memory safety and high performance.

View on GitHub Get Started

Key Features

Powerful capabilities that set MirDB apart

Memcached Protocol

Drop-in replacement compatibility with the memcached protocol. Use your existing memcached clients and libraries without any code changes.

Persistent Storage

Built on LSM-tree architecture for durable data persistence. Your data survives restarts with write-ahead logging and efficient compaction.

High Performance

Skip list-based memtable for fast in-memory writes. SSTable compaction ensures optimal read performance and efficient disk usage.

Rust Implementation

Written in Rust for memory safety and high performance. No garbage collection pauses, zero-cost abstractions, and fearless concurrency.

Usage & Examples

Get started with MirDB using familiar memcached commands

Basic Storage Commands

MirDB supports the standard memcached text protocol. Connect using telnet or any memcached client.

SET - Store a value

Store a key-value pair with optional expiration time.

bash 
# Connect to MirDB server
telnet localhost 11211

# SET command syntax: set <key> <flags> <exptime> <bytes>
set mykey 0 3600 5
hello
STORED

GET - Retrieve a value

Retrieve one or more values by key.

bash 
# GET command syntax: get <key>
get mykey
VALUE mykey 0 5
hello
END

Additional Commands

MirDB supports the full range of memcached storage and manipulation commands.

ADD - Store only if key doesn't exist

Store a value only if the key does not already exist.

bash 
# ADD command: add <key> <flags> <exptime> <bytes>
add newkey 0 0 5
world
STORED

REPLACE - Update existing key only

Update a value only if the key already exists.

bash 
# REPLACE command: replace <key> <flags> <exptime> <bytes>
replace mykey 0 0 6
updated
STORED

APPEND - Add data to end of existing value

Append data to the end of an existing value.

bash 
# APPEND command: append <key> <flags> <exptime> <bytes>
append mykey 0 0 6
_suffix
STORED

PREPEND - Add data to beginning of existing value

Prepend data to the beginning of an existing value.

bash 
# PREPEND command: prepend <key> <flags> <exptime> <bytes>
prepend mykey 0 0 7
prefix_
STORED

DELETE - Remove a key

Delete a key-value pair from the store.

bash 
# DELETE command: delete <key>
delete mykey
DELETED

Getting Started

Build MirDB from source and connect with memcached clients

Installation

MirDB is written in Rust. Build it from source using cargo.

1. Clone the repository

bash 
git clone https://github.com/yetone/mirdb.git
cd mirdb

2. Build with Cargo

bash 
# Build in release mode for best performance
cargo build --release

# The binary will be at target/release/mirdb-server

3. Run the server

bash 
# Run the server (listens on port 12333 by default)
./target/release/mirdb-server

# Data is stored in /tmp/mirdb by default

Connecting to MirDB

Connect using telnet or any memcached-compatible client on port 12333.

Using Telnet

bash 
# Connect to MirDB using telnet
telnet localhost 12333

# Now you can use memcached commands:
set mykey 0 0 5
hello
STORED

get mykey
VALUE mykey 0 5
hello
END

Using a Memcached Client

You can use any memcached client library. Here's an example with Python:

python 
from pymemcache.client import base

# Connect to MirDB on port 12333
client = base.Client(('localhost', 12333))

# Store a value
client.set('greeting', 'Hello, MirDB!')

# Retrieve it
result = client.get('greeting')
print(result)  # b'Hello, MirDB!'
Default Configuration

MirDB listens on 0.0.0.0:12333 by default and stores data in /tmp/mirdb. Check the project documentation for configuration options.
