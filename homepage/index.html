MirDB

A persistent key-value store with Memcached protocol compatibility. Fast, reliable, and simple to deploy.

Get Started Learn More

Features

Built for developers who need a simple, persistent key-value store.

Persistent Storage

Data is persisted to disk using an LSM-tree architecture, ensuring durability across restarts.

Memcached Protocol

Full compatibility with the Memcached text protocol. Use existing clients and libraries.

Skiplist Memtable

Fast in-memory writes using a concurrent skiplist data structure for optimal performance.

Compaction

Automatic background compaction keeps the database optimized and reclaims disk space.

Usage Examples

Interact with MirDB using standard Memcached protocol commands. 

# Connect to MirDB using telnet or nc
$ telnet localhost 11211

# Store a value
set mykey 0 0 5
hello
STORED

# Retrieve a value
get mykey
VALUE mykey 0 5
hello
END

# Delete a value
delete mykey
DELETED

Quick Start

Get MirDB up and running in minutes.

1

Clone and Build

git clone https://github.com/something/mirdb.git
cd mirdb
make build
2

Start the Server

./mirdb --port 11211 --data-dir ./data
3

Connect with a Client

# Using telnet
telnet localhost 11211

# Or using any Memcached client library
from pymemcache.client import base
client = base.Client(('localhost', 11211))
client.set('key', 'value')
