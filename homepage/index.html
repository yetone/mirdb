MirDB

A persistent key-value store with Memcached protocol support

Get Started

Features

  • Memcached Protocol

    Full compatibility with the Memcached text protocol for seamless integration with existing clients.

  • SkipList Memtable

    Fast in-memory data structure for efficient ordered key lookups and range scans.

  • Minor / Major Compaction

    Automatic background compaction to optimize storage and reduce read amplification.

  • Persistent Storage

    Durable LSM-tree based storage engine with Write-Ahead Log for crash recovery.

Installation

Get MirDB up and running in seconds.

Via Cargo

cargo install mirdb

Pre-built Binary

curl -sSL https://github.com/yetone/mirdb/releases/latest/download/mirdb-linux-x64.tar.gz | tar xz
./mirdb

Or download the latest release from the GitHub releases page.

Usage

Interact with MirDB using standard Memcached commands.

# Set a key-value pair
set mykey 0 0 5
hello

# Get a value
get mykey

# Delete a key
delete mykey

Architecture

MirDB uses an LSM-tree based storage engine for efficient write operations and crash recovery.
