MirDB

A Persistent Key-Value Store implementing the Memcached protocol. Built with Rust and powered by an LSM-tree storage engine.

Get Started

Features

Powerful capabilities for modern applications

Persistent Storage

Data durability guaranteed with persistent storage on disk. Your data survives restarts and system failures.

Memcached Protocol

Drop-in compatibility with the Memcached protocol. Use existing clients and tools without modification.

LSM-tree Storage Engine

Log-Structured Merge-tree architecture optimized for write-heavy workloads with excellent read performance.

Skip-list Memtable

In-memory skip-list data structure providing O(log n) operations for fast lookups and ordered iteration.

Compaction Support

Automatic minor and major compaction to optimize storage and maintain query performance over time.
