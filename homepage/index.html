Features

Powerful capabilities for persistent key-value storage

⚡

Tokio with Memcached Protocol

High-performance async runtime with full Memcached protocol support. Connect with any Memcached client and enjoy blazing-fast operations.

Implemented
📊

Memtable with Skip-List

Efficient in-memory data structure using skip-list for fast lookups, insertions, and range queries with O(log n) complexity.

Implemented
🔄

Minor Compaction

Automatic flushing of memtable to SSTable files when memory threshold is reached, ensuring data durability without blocking writes.

Implemented
🗜️

Major Compaction

Background process that merges multiple SSTable files to reclaim space, remove deleted entries, and optimize read performance.

Implemented
