MirDB

A Persistent Key-Value Store with Memcached Protocol

Simple, fast, and durable key-value storage written in Rust

Rust Tokio LSM-Tree
Get Started

Quick Start

Get up and running with MirDB in minutes.

1. Install MirDB

Install MirDB using Cargo, the Rust package manager:

bash 
cargo install mirdb

2. Start the Server

Start the MirDB server with a data directory:

bash 
mirdb-server --data-dir ./data

3. Connect to the Server

Connect to MirDB using telnet on the default Memcached port:

bash 
telnet localhost 11211

4. Basic Operations

Use standard Memcached protocol commands to set and get values:

memcached 
# Set a value
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

Features

  • Tokio Async Runtime

    Built on Tokio for high-performance asynchronous I/O operations.

  • Skip-List Memtable

    Efficient in-memory data structure for fast reads and writes.

  • Write-Ahead Log

    Ensures data durability with crash recovery support.

  • Minor Compaction

    Automatic background compaction of memtables to SSTables.

  • Major Compaction

    Merges SSTables to optimize storage and read performance.

  • Memcached Protocol

    Compatible with standard Memcached clients and tools.

Configuration

Port Configuration

Configure the server port (default: 11211):

bash 
mirdb-server --port 11211

Data Directory

Specify where MirDB stores its data files:

bash 
mirdb-server --data-dir /var/lib/mirdb

WAL Settings

Configure Write-Ahead Log for durability:

bash 
mirdb-server --data-dir ./data --wal-sync
