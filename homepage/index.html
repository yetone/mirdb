MirDB

A persistent key-value store with memcached protocol compatibility

High-performance storage engine built with Rust, featuring LSM tree architecture and automatic compaction.

Features

🔌

Memcached Protocol Compatible

Full compatibility with the memcached protocol. Use existing memcached clients and tools seamlessly with MirDB as a drop-in replacement.

💾

Persistent Storage

Unlike in-memory caches, MirDB provides durable persistent storage. Your data survives restarts and system failures.

🌳

LSM Tree Architecture

Built on Log-Structured Merge tree architecture for optimal write performance and efficient storage utilization.

📊

Skiplist Memtable

High-performance skiplist-based memtable implementation for fast in-memory operations before data is flushed to disk.

⚡

Automatic Compaction

Intelligent minor and major compaction processes run automatically to optimize storage and maintain read performance.
