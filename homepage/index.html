MirDB

A persistent key-value store with memcached protocol compatibility. Your data survives restarts.

Get Started View on GitHub

Key Features

Memcached Protocol

Works with existing memcached clients. Supports SET, GET, DELETE, ADD, REPLACE, APPEND, and PREPEND commands.

Persistent Storage

Unlike standard memcached, MirDB persists data to disk using SSTables. Your data survives restarts.

LSM Tree Architecture

Built on Log-Structured Merge-tree with memtables, immutable memtables, and multi-level SSTable compaction.

Async I/O

Powered by Tokio for high-performance async networking and I/O operations.

Getting Started

Connect with any memcached client

# Using telnet
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
# Response: STORED

# Get a value
get mykey
# Response: VALUE mykey 0 5
#           hello
#           END

# Delete a value
delete mykey
# Response: DELETED

Configuration

# mirdb.toml
addr = "0.0.0.0:12333"
max_level = 7
work_dir = "/tmp/mirdb"
sst_max_size = "100M"
mem_table_max_size = "4M"
block_size = "4K"
l0_compaction_trigger = 4
