MirDB

A Persistent Key-Value Store with Memcached protocol support, written in Rust

Get Started Documentation

Features

Memcached Protocol

Drop-in compatible with existing Memcached clients. Use your favorite language and library to connect.

LSM-Tree Storage

Efficient log-structured merge-tree engine for high-performance persistent storage with optimized write paths.

Write-Ahead Logging

Durable writes with crash recovery support. Your data is safe even during unexpected shutdowns.

Auto Compaction

Background minor and major compaction keeps storage optimized without manual intervention.

LRU Block Cache

In-memory caching for fast repeated reads with intelligent least-recently-used eviction.

Snappy Compression

Efficient data compression reduces storage footprint while maintaining fast read/write speeds.

Cuckoo Filter

Fast probabilistic key existence checks to minimize unnecessary disk reads.

Rust Performance

Memory-safe systems programming with zero-cost abstractions for maximum performance and reliability.

Architecture

MirDB uses a Log-Structured Merge-tree (LSM-tree) architecture for efficient persistent storage with optimized write performance and automatic background compaction.

How It Works

  • Write-Ahead Log (WAL): All writes are first recorded to the WAL for durability, ensuring data safety even during crashes.
  • Memtable: Writes are stored in an in-memory skip list for fast access. When the memtable reaches capacity, it becomes immutable.
  • Compaction: Minor compaction flushes immutable memtables to Level 0 SSTables. Major compaction merges SSTables across levels, optimizing storage and read performance.
  • SSTable Levels: Data is organized in levels, with each level holding more data. Cuckoo filters enable fast key lookups without reading disk.

Quick Start

Get up and running with MirDB in minutes. Use standard Memcached commands to interact with your data.

Installation 
# Install MirDB server
cargo install mirdb-server

# Start the server
mirdb-server --config etc/mirdb.toml
Basic Usage 
# Connect to MirDB
telnet localhost 11211

# Store a value
set mykey 0 0 5
hello
STORED

# Retrieve the value
get mykey
VALUE mykey 0 5
hello
END
