MirDB

Persistent Memcached-Compatible Key-Value Store

The speed of Memcached with the durability you need. Built on a proven LSM tree architecture.

Get Started on GitHub View Quick Start

Features

Memcached Protocol

Fully compatible with the Memcached protocol. Use your existing memcached clients without any code changes.

Durable Persistence

Built on LSM tree architecture for durable storage. Your data persists across restarts and server failures.

TTL Support

Set expiration times on keys with full TTL support. Keys automatically expire when their time-to-live is reached.

Fault Tolerance

Write-Ahead Log (WAL) ensures crash recovery. Recover seamlessly from unexpected shutdowns without data loss.

Compaction

Automatic background compaction merges and optimizes storage files, keeping your database lean and efficient.

High Performance

Optimized for low-latency reads and writes. Get the speed of an in-memory cache with persistent storage.

Quick Start

Get started with MirDB using your favorite Memcached client. MirDB is fully compatible with the Memcached protocol.

Python 
from pymemcache.client.base import Client

# Connect to MirDB on localhost:12333
client = Client(('localhost', 12333))

# Set a key-value pair
client.set('greeting', 'Hello, MirDB!')

# Retrieve the value
result = client.get('greeting')
print(result)  # b'Hello, MirDB!'
Go 
package main

import (
    "github.com/bradfitz/gomemcache/memcache"
    "log"
)

func main() {
    // Connect to MirDB on localhost:12333
    mc := memcache.New("localhost:12333")

    // Set a key-value pair
    mc.Set(&memcache.Item{Key: "greeting", Value: []byte("Hello, MirDB!")})

    // Retrieve the value
    item, err := mc.Get("greeting")
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("%s", item.Value)
}
