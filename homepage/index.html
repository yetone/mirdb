Features

MirDB comes packed with powerful features for high-performance key-value storage.

Tokio Async Runtime

Built on Tokio for high-performance asynchronous I/O. Handle thousands of concurrent connections efficiently with non-blocking operations.

Skip-List Memtable

High-performance memtable using skip-list data structure. Provides fast O(log n) lookups and insertions with efficient in-memory storage.

Minor Compaction

Automatic minor compaction flushes memtable data to disk as sorted string tables (SSTables), ensuring data persistence and memory efficiency.

Major Compaction

Background major compaction merges SSTables to reduce storage overhead, improve read performance, and reclaim disk space from deleted entries.

Write-Ahead Log

Durable write-ahead logging ensures data safety. All writes are logged before acknowledgment, enabling crash recovery without data loss.

Memcached Protocol

Full compatibility with the Memcached text protocol. Use existing Memcached clients and tools without any code changes.
