Quick Start

MirDB uses the standard memcached text protocol. Connect using telnet or any memcached client:

Connect to MirDB

# Connect using telnet
telnet localhost 12333

Store and Retrieve Data

# Set a key-value pair
# set <key> <flags> <ttl> <bytes>
set mykey 0 0 5
hello
STORED

# Get the value
get mykey
VALUE mykey 0 5
hello
END

Delete Data

# Delete a key
delete mykey
DELETED

# Verify deletion
get mykey
END

Database Info

# Get database status (MirDB-specific)
info
