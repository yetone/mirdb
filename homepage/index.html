MirDB

A Persistent Key-Value Store with Memcached Protocol

Get Started View on GitHub
Memcached Compatible Persistent Storage Built with Rust

Key Features

Built for performance, reliability, and ease of use. MirDB combines the simplicity of Memcached with the durability of disk-based storage.

Memcached Protocol

Drop-in compatible with existing memcached clients. Use your favorite libraries and tools without code changes.

Persistent Storage

Your data survives restarts. MirDB persists to disk using efficient SSTable format, ensuring durability without sacrificing speed.

LSM Tree Architecture

Built on Log-Structured Merge Tree with skip-list memtable, minor and major compaction for optimal write performance.

Async Tokio Networking

High-performance async I/O powered by Tokio. Handle thousands of concurrent connections efficiently with Rust's safety guarantees.

Quick Start

MirDB is compatible with standard memcached clients. Here's how to get started with basic SET and GET operations:

Python 
# Connect to MirDB using pymemcache
from pymemcache.client.base import Client

# Create a client connection
client = Client(('localhost', 11211))

# SET a key-value pair
client.set('my_key', 'Hello, MirDB!')

# GET the value back
value = client.get('my_key')
print(value)  # Output: b'Hello, MirDB!'

# SET with expiration (60 seconds)
client.set('temp_key', 'temporary', expire=60)

# GET multiple keys
client.set('key1', 'value1')
client.set('key2', 'value2')
values = client.get_many(['key1', 'key2'])

MirDB supports all standard memcached commands including set, get, delete, incr, and decr. Data is automatically persisted to disk using SSTables and LSM Tree architecture.
