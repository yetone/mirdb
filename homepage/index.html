MirDB

Persistent Key-Value Store with Memcached Protocol

Get Started View on GitHub

Features

Memcached Protocol Compatible

Drop-in replacement for memcached. Use your existing client libraries and tools without any code changes.

Persistent Storage

Data survives restarts with durable SSTables. Never lose your cached data again with built-in persistence.

LSM Tree Architecture

Built on a Log-Structured Merge Tree for optimal write performance and efficient storage compaction.

Async/Tokio Networking

High-performance async networking powered by Tokio for maximum concurrency and throughput.

Quick Start

bash 
# Installation
cargo install mirdb

# Start the server
mirdb

# Connect and use (same as memcached)
telnet localhost 12333
SET key 0 0 5
hello
STORED
GET key
VALUE key 0 5
hello
END
