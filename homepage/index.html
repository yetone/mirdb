Quick Start

Get up and running with MiRDB in just a few minutes. Choose your preferred installation method below.

Installation

  1. Download Pre-built Binary

    Download the latest pre-built binary from the GitHub Releases page for your platform.

  2. Or Install via Cargo

    If you have Rust installed, you can build from source:

    cargo install mirdb
  3. Run the Server

    Start the MiRDB server with the default configuration:

    mirdb-server
  4. Connect with a Client

    Use any memcached-compatible client or telnet to connect:

    telnet localhost 12333

Basic Usage

Once connected, you can use standard memcached commands:

# Store a value
SET mykey 0 0 5
hello
STORED

# Retrieve a value
GET mykey
VALUE mykey 0 5
hello
END

For more detailed documentation and advanced configuration options, visit the GitHub repository.
