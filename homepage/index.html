MirDB: A Persistent Key-Value Store with Memcached Protocol

Compatible with memcached clients, but with disk persistence for durability. Drop-in replacement that stores your data safely to disk.

Get Started View Code

What is MirDB?

MirDB is a persistent key-value store that speaks the Memcached protocol.

Unlike traditional Memcached which stores data only in memory, MirDB persists your data to disk using SSTables (Sorted String Tables). This means your data survives server restarts and crashes while still offering the familiar Memcached interface you already know.

MirDB is built on a Log-Structured Merge-tree (LSM tree) architecture, the same proven technology used by databases like LevelDB, RocksDB, and Cassandra. This design optimizes for write-heavy workloads while maintaining excellent read performance.

Under the Hood

  • SSTable Storage: Data is organized into immutable sorted files for efficient reads and disk usage
  • LSM Tree Architecture: Multi-level structure with background compaction for sustained performance
  • Write-Ahead Logging: Ensures durability with crash recovery capabilities
  • Memcached Protocol: Drop-in compatible with existing Memcached clients

Features

Memcached Protocol

Drop-in compatible with existing memcached clients. Use your favorite memcached libraries without any code changes.

Disk Persistence

Your data survives restarts and crashes. Persistent storage ensures durability without sacrificing performance.

LSM Tree Architecture

Built on a Log-Structured Merge tree for optimal write performance and efficient storage utilization.

Multi-Level Compaction

Intelligent multi-level compaction strategy keeps storage efficient while maintaining fast read and write performance.

Async I/O

Asynchronous I/O operations ensure high throughput and low latency even under heavy workloads.

Rust Powered

Built with Rust for memory safety, zero-cost abstractions, and fearless concurrency.

Quick Start

Get up and running with MirDB in three simple steps

1

Install MirDB

Build from source using Cargo, Rust's package manager:

cargo install mirdb-server

Or clone and build from the repository:

git clone https://github.com/penberg/mirdb.git
cd mirdb
cargo build --release
2

Start the Server

Run MirDB with default configuration:

mirdb-server

Default Configuration:

  • Port: 12333
  • Work Directory: /tmp/mirdb

Or specify custom options:

mirdb-server --port 12333 --work-dir /tmp/mirdb
3

Connect with a Client

Use any memcached-compatible client to connect. Here's an example using telnet:

# Connect to MirDB
telnet localhost 12333

# Or use memcat from libmemcached-tools
memcat --servers=localhost:12333 mykey

MirDB is fully compatible with memcached clients in Python, Node.js, Ruby, and more.

Code Example

Start the MirDB server and connect using any Memcached client

Shell 
# Start MirDB server on default port 12333
./mirdb-server --port 12333 --work-dir /var/lib/mirdb

# Or run from source with cargo
cargo run --release -- --port 12333
Python 
# Connect using any Memcached client
import pymemcache
from pymemcache.client import base

# Connect to MirDB (same as Memcached!)
client = base.Client(('localhost', 12333))

# Store a value - persisted to disk
client.set('user:1', 'Alice')

# Retrieve the value
result = client.get('user:1')
print(result)  # Output: b'Alice'
