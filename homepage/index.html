MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance, durable key-value store that speaks memcached. Drop-in replacement with data persistence - it's painless as using memcached.

Get Started View on GitHub

Key Features

Everything you need for persistent, high-performance key-value storage

Memcached Compatible

Drop-in replacement for memcached clients. Uses the standard memcached text protocol, allowing existing clients to connect seamlessly without any code changes.

Persistent Storage

Unlike memcached, MirDB persists data to disk using SSTable (Sorted String Table) format. Your data survives restarts with durable disk persistence.

High Performance

Built with Rust and powered by Tokio async I/O for blazing fast performance. Zero-cost abstractions and memory safety without garbage collection overhead.

LSM Tree Architecture

Log-Structured Merge-tree design optimized for write-heavy workloads. Efficient batching of writes with multi-level compaction for optimal read performance.

Skip List Memtable

In-memory operations use a highly efficient skip list data structure. O(log n) search, insert, and delete with lock-free concurrent access capabilities.

Automatic Compaction

Both minor and major compaction are fully supported. Automatic background compaction keeps storage efficient and query performance optimal over time.

Quick Start

Get up and running in minutes

bash 
# Clone the repository
git clone https://github.com/yetone/mirdb.git

# Build the project
cargo build --release

# Run MirDB server
./target/release/mirdb-server

Usage Example

terminal 
$ telnet localhost 12333
set mykey 0 0 5
hello
STORED
get mykey
VALUE mykey 0 5
hello
END
