MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance key-value store that combines the simplicity of the Memcached protocol with the durability of persistent storage. Built with Rust for reliability and speed.

Get Started View on GitHub

Key Features

Memcached Compatible

Use existing memcached clients and libraries. Drop-in replacement with zero code changes. Supports GET, SET, DELETE, and other standard commands.

Built-in Persistence

Unlike memcached, your data survives restarts. SSTables (Sorted String Tables) ensure durability without sacrificing speed.

LSM-Tree Architecture

Write-optimized storage engine with automatic compaction. Handles high write throughput efficiently using Log-Structured Merge-tree design.

Simple Configuration

TOML-based configuration with sensible defaults. Get started with minimal setup and customize as needed.

Quick Start

# Start MirDB server
mirdb -c /path/to/config.toml

# Connect with any memcached client
telnet localhost 12333

# Store a value
set mykey 0 0 5
hello
STORED

# Retrieve the value
get mykey
VALUE mykey 0 5
hello
END

Getting Started

1. Install

cargo install mirdb

2. Configure

[server]
listen_addr = "0.0.0.0:12333"

[storage]
work_dir = "/var/lib/mirdb"
max_lsm_levels = 7
sstable_max_size = 104857600
memtable_max_size = 4194304

3. Run

mirdb -c config.toml
