About MirDB

MirDB is a persistent key-value store implemented in Rust, featuring Memcached protocol compatibility. It provides reliable, high-performance data storage using an LSM-tree architecture with async I/O powered by Tokio.

Key Features

  • Memcached Protocol

    Seamlessly integrate with existing memcached clients and tools

  • Persistent Storage

    LSM-tree based storage engine ensures data durability

  • Rust Implementation

    Memory safety and performance without compromise

  • Async I/O

    High concurrency with Tokio runtime

  • Skip-list Memtable

    Efficient in-memory data structure for fast writes

  • SSTable Compaction

    Automatic background compaction for optimized reads

Quick Start

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build and run
cargo build --release
cargo run --release

# Connect using any memcached client
# Example with telnet:
telnet localhost 11211
