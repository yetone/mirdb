# MirDB Homepage

Public landing page for MirDB - a persistent key-value store with Memcached protocol support.

## Development

```bash
# Install dependencies
npm install

# Run all tests
npm test

# Run specific test suites
npm run test:unit
npm run test:integration
npm run test:e2e

# Serve locally
npm run dev
```

## Structure

- `sections/` - HTML partials for each page section
- `css/` - Stylesheets
- `js/` - JavaScript modules
- `assets/` - Images and icons
- `tests/` - Unit, integration, and e2e tests
