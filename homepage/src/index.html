What is MirDB?

MirDB is a high-performance persistent key-value store written in Rust. It implements the Memcached protocol, allowing seamless integration with existing Memcached clients while providing durable storage through LSM tree architecture with SSTables for persistence.

Key Features

Built with performance and reliability in mind

🔌

Memcached Protocol

Fully compatible with the Memcached protocol. Use your existing Memcached clients without any code changes.

💾

Persistent Storage

Data is durably stored using SSTables (Sorted String Tables) ensuring your data survives restarts and crashes.

🌲

LSM Tree Architecture

Log-Structured Merge tree architecture provides excellent write performance and efficient storage utilization.

📋

Skip List Memtable

In-memory skip list data structure for fast reads and writes before data is flushed to disk.

🔄

Compaction

Automatic minor and major compaction processes merge SSTables to reclaim space and improve read performance.

Usage

MirDB uses the standard Memcached protocol. Connect with any Memcached client or use telnet to interact with the database.

Set a Key-Value Pair 
$ telnet localhost 12333
set mykey 0 0 5
hello
STORED

set command

Store a value with a key. Format: set <key> <flags> <exptime> <bytes>

Retrieve a Value 
get mykey
VALUE mykey 0 5
hello
END

get command

Retrieve a value by key. Returns the value along with metadata.
