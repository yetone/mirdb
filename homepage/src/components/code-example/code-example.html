Get Started

Connect with any Memcached client. Here are the basics over the text protocol: 

# Start the server
mirdb-server --port 11211

# In another shell, use any memcached client:
set hello 0 0 5
world
# STORED

get hello
# VALUE hello 0 5
# world
# END

add counter 0 0 1
0
# STORED

replace hello 0 0 5
MirDB
# STORED

delete counter
# DELETED
