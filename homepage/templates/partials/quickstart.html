Quick Start

Installation

Install MirDB using Cargo:

bash 
# Install from crates.io
cargo install mirdb

# Or build from source
git clone https://github.com/mirdb/mirdb.git
cd mirdb
cargo build --release

Basic Usage

Start the MirDB server:

bash 
# Start MirDB server (default port: 12333)
mirdb

Connect using any memcached client or netcat:

bash 
# Connect with netcat
nc localhost 12333

# Set a key-value pair (memcached protocol)
set mykey 0 0 5
hello
# Response: STORED

# Get the value back
get mykey
# Response: VALUE mykey 0 5
#           hello
#           END
