Quick Start

Connect with any memcached client and start storing data

# Connect to MirDB
$ telnet localhost 12333

# Store a value (persists across restarts)
SET mykey 0 0 5
hello
STORED
# Retrieve stored data
GET mykey
VALUE mykey 0 5
hello
END
# Delete a key
DELETE mykey
DELETED

# Verify deletion
GET mykey
END
