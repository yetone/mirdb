Performance & Configuration

Performance Characteristics

MirDB is optimized for write-heavy workloads using an LSM-tree architecture that provides:

  • High Write Throughput: Sequential writes to memory tables with background compaction
  • Efficient Reads: Bloom filters and block indexes minimize disk I/O
  • Configurable Memory: Tunable memtable sizes for memory vs. durability tradeoffs
  • Background Compaction: Automatic level-based compaction maintains read performance

Configuration Options

Configure MirDB via TOML configuration file (-c /path/to/config.toml):

Option Default Description
addr 0.0.0.0:12333 Server bind address and port
max_level 7 Maximum number of LSM-tree levels
work_dir /tmp/mirdb Data directory path for persistent storage
sst_max_size 100MB Maximum SSTable file size before splitting
mem_table_max_size 4MB Maximum memtable size before flush to disk
block_size 4KB Data block size for SSTable storage
