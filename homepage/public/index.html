MirDB

A Persistent Memcached-Compatible Key-Value Store

Drop-in replacement for Memcached with data persistence. Built with Rust and powered by LSM tree architecture for high-performance storage that survives restarts.

Get Started View on GitHub

Key Features

Memcached Protocol

Compatible with standard Memcached text protocol. Use your existing clients without any code changes.

Persistent Storage

Unlike in-memory Memcached, MirDB persists data to disk using SSTables. Your data survives restarts.

LSM Tree Architecture

Production-grade storage engine with memtables, WAL, and multi-level SSTable compaction.

Async Performance

Built on Tokio for high-concurrency workloads with non-blocking I/O.

How It Works

MirDB uses an LSM (Log-Structured Merge) tree architecture for high-performance, durable storage.

1. Write-Ahead Log (WAL)

Every write is first recorded in the WAL for durability. If the server crashes, data can be recovered from the log.

2. Memtable

Data is stored in a fast, in-memory skip list. This enables quick writes and reads for recent data.

3. SSTable Levels

When the Memtable fills up, it's flushed to disk as sorted string tables. Background compaction merges and organizes data across levels for efficient storage and retrieval.

Quick Start

Get up and running with MirDB in under 5 minutes.

1. Install MirDB

bash 
# Install from crates.io
cargo install mirdb

# Or clone and build from source
git clone https://github.com/mirdb/mirdb.git
cd mirdb
cargo build --release

2. Start the Server

bash 
# Start MirDB server
./mirdb -c mirdb.toml

3. Connect and Use

bash 
# Connect with any memcached client
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
# Response: STORED

# Get the value
get mykey
# Response: VALUE mykey 0 5
# hello
# END

Configuration

Configure MirDB using a TOML configuration file. Below are the key settings and their default values.

Setting Default Value
Listen Address 0.0.0.0:12333
Work Directory /tmp/mirdb
Max LSM Levels 7
Memtable Size 4MB
SSTable Size 100MB
Block Size 4KB
