MirDB

A Persistent Memcached-Compatible Key-Value Store

Drop-in replacement for Memcached with data persistence. Built with Rust and powered by LSM tree architecture for high-performance storage that survives restarts.

Get Started View on GitHub

Key Features

Memcached Protocol

Compatible with standard Memcached text protocol. Use your existing clients without any code changes.

Persistent Storage

Unlike in-memory Memcached, MirDB persists data to disk using SSTables. Your data survives restarts.

LSM Tree Architecture

Production-grade storage engine with memtables, WAL, and multi-level SSTable compaction.

Async Performance

Built on Tokio for high-concurrency workloads with non-blocking I/O.

Quick Start

bash 
# Start MirDB server
./mirdb -c mirdb.toml

# Connect with any memcached client
telnet localhost 12333

# Set a value
set mykey 0 0 5
hello
# Response: STORED

# Get the value
get mykey
# Response: VALUE mykey 0 5
# hello
# END
