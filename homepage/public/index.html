MirDB

Persistent Key-Value Store with Memcached Protocol

A high-performance, durable storage solution built in Rust with LSM-tree architecture

Get Started GitHub

Key Features

Memcached Protocol

Drop-in replacement with full memcached text protocol support. Use existing clients without modification.

Persistent Storage

Data survives restarts with SSTable persistence and Write-Ahead Log for durability.

Built in Rust

Memory-safe, high-performance implementation with async I/O powered by Tokio.

Quick Start

# Clone the repository
git clone https://github.com/yetone/mirdb.git
cd mirdb

# Build the project
cargo build --release

# Run with default configuration
./target/release/mirdb -c etc/mirdb.toml
