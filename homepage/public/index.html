MirDB

Persistent key-value store with the Memcached protocol — built in Rust.

View on GitHub Read Documentation

Features

Every piece you need from a modern key-value store, packaged behind the familiar Memcached wire protocol.

  • Memcached Protocol

    Drop-in compatibility with the standard Memcached text protocol means existing clients connect without changes.

  • Built in Rust

    Memory safety, fearless concurrency, and predictable performance thanks to a modern systems language.

  • Persistent Storage

    Unlike pure in-memory caches, MirDB durably persists every write to disk for safe long-term storage.

  • LSM Tree Architecture

    A log-structured merge tree powers high write throughput with efficient on-disk layout across levels.

  • Skip-List Memtable

    An in-memory skip list provides ordered, lock-friendly inserts and lookups for the hottest data.

  • WAL Durability

    A Write-Ahead Log records every mutation before acknowledgement, guaranteeing crash recovery.

  • Background Compaction

    Minor and major compaction continuously merge SSTables to reclaim space and keep reads fast.

Get Started

Connect with any Memcached client. Here are the basics over the text protocol: 

# Start the server
mirdb-server --port 11211

# In another shell, use any memcached client:
set hello 0 0 5
world
# STORED

get hello
# VALUE hello 0 5
# world
# END

add counter 0 0 1
0
# STORED

replace hello 0 0 5
MirDB
# STORED

delete counter
# DELETED

Why MirDB?

Built in Rust for memory safety and performance, MirDB packs an LSM tree (Log-Structured Merge) storage engine with built-in compaction behind the familiar Memcached protocol — and Raft consensus is on the roadmap for distributed deployments.

  • vs

    Memcached

    MirDB writes every value to durable disk storage — your data stays persistent across restarts, where Memcached lives purely in memory and forgets on shutdown.

  • vs

    Redis

    MirDB chooses simplicity and Memcached protocol compatibility over Redis's much larger command surface — a tiny wire format your existing clients already speak.

  • vs

    RocksDB

    MirDB ships with a network protocol out of the box, so any Memcached client can talk to it; RocksDB is an embedded library you have to wrap yourself.
