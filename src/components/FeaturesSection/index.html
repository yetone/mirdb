Implemented Features

  • Tokio async networking

    Asynchronous network operations powered by Rust's Tokio runtime for high-performance I/O handling.

  • Memtable with skip-list

    In-memory data structure using skip-list for efficient writes and reads before flushing to disk.

  • Minor/Major compaction

    Background process that merges SSTables to optimize read performance and reclaim disk space.

Planned Features

  • Raft consensus

    Distributed consensus algorithm for building fault-tolerant clustered deployments (planned for future release).

Technology Stack

Rust Tokio LSM Tree
