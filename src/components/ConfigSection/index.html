Quick Start

  1. Install MirDB: 
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
cargo install mirdb
  2. Start the server: 
    mirdb start --port 11211
  3. Verify it's working: 
    echo "set test 0 0 5\nhello\n" | nc localhost 11211
      echo "get test" | nc localhost 11211

Version: v1.4.0 (matches latest GitHub release)

Note: MirDB currently supports Linux and macOS. Windows support coming in Q3 2026.
