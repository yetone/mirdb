Installation

Get MirDB running on your system in minutes. Choose the method that works best for your platform.

System Requirements

  • Rust Toolchain: Rust 1.70+ (stable channel)
  • Operating System: Linux (kernel 3.10+) or macOS (10.14+)
  • Disk Space: At least 100 MB free for binaries and data
  • Memory: 512 MB RAM minimum (4 GB recommended for production)
  • Network: Port 12333 available (configurable)

Linux Installation

Option 1: Install from crates.io

cargo install mirdb-server

Option 2: Build from Source

# Clone the repository
git clone https://github.com/mirdb/mirdb.git
cd mirdb

# Build the release binary
cargo build --release

# The binary will be available at:
# ./target/release/mirdb-server

Option 3: Download Pre-built Binary

# Download the latest release (x86_64)
curl -L -o mirdb-server https://github.com/mirdb/mirdb/releases/latest/download/mirdb-server-linux-x86_64
chmod +x mirdb-server
sudo mv mirdb-server /usr/local/bin/

macOS Installation

Option 1: Install with Homebrew

brew install mirdb

Option 2: Install from crates.io

cargo install mirdb-server

Option 3: Build from Source

# Clone the repository
git clone https://github.com/mirdb/mirdb.git
cd mirdb

# Build the release binary
cargo build --release

# The binary will be available at:
# ./target/release/mirdb-server

Configuration Setup

After installation, create a configuration file at mirdb.toml:

addr = "0.0.0.0:12333"
work_dir = "/tmp/mirdb"
mem_table_max_size = 4194304
sstable_max_size = 104857600
block_size = 4096
max_level = 7

If no configuration file is provided, MirDB will use sensible defaults.

Configuration

MirDB is highly configurable. Tune these parameters to match your workload and deployment environment.

Network

Parameter Description Default
addr Listen address and port for client connections 0.0.0.0:12333

Network configuration parameters

Storage

Parameter Description Default
work_dir Directory path where data files are stored /tmp/mirdb
max_level Maximum number of LSM tree levels 7

Storage configuration parameters

Memory Tables

Parameter Description Default
mem_table_max_size Maximum memtable size before flushing to disk 4M
mem_table_max_height Maximum skip list height for in-memory index 32
imm_mem_table_max_count Maximum number of queued immutable memtables 16

Memory table configuration parameters

SSTables

Parameter Description Default
sst_max_size Maximum size of a single SSTable file 100M
block_size Size of each data block within an SSTable 4K
block_restart_interval Interval at which full keys are stored in blocks for prefix compression 16

SSTable configuration parameters

Compaction

Parameter Description Default
l0_compaction_trigger Number of Level 0 files that trigger background compaction 4
thread_sleep_ms Background compaction thread sleep interval in milliseconds 500

Compaction configuration parameters

For a complete list of all configuration options, including advanced tuning parameters, see the full configuration documentation →

Note: Size values support suffix notation: K (kilobytes), M (megabytes), G (gigabytes), and T (terabytes). For example, mem_table_max_size = "4M" is equivalent to 4194304 bytes.
