MirDB: A Persistent Key-Value Store

A high-performance, persistent key-value store with full memcached protocol compatibility. Built with an LSM tree architecture for durability and speed.

Features

Persistent Storage

All data is persisted to disk, ensuring durability across restarts. Your key-value pairs survive server crashes and power failures.

Memcached Protocol

Full compatibility with the memcached text protocol. Use existing memcached clients and tools without any modifications.

LSM Tree Architecture

Built on a Log-Structured Merge-tree for optimal write performance. Efficiently handles high-throughput workloads with sequential disk writes.

Skip-List Memtable

Uses a skip-list based memtable for fast in-memory operations. Provides O(log n) insertions and lookups with low memory overhead.

Intelligent Compaction

Supports both minor and major compaction strategies. Automatically merges and optimizes SSTables to reclaim space and improve read performance.
