MirDB: A Persistent Key-Value Store with Memcached Protocol

Lightweight, efficient, and compatible with the Memcached ecosystem

Get Started View Source

Features

  • ✅ Persistent storage with LSM Tree architecture
  • ✅ Full Memcached protocol compatibility
  • ✅ Async networking with Tokio
  • ✅ Memtable with skip-list implementation
  • ✅ Minor/major compaction
  • 🔜 Raft consensus (planned)

Usage

Basic Memcached Commands

set mykey 0 0 7
Hello
STORED

get mykey
VALUE mykey 0 7
Hello
END
