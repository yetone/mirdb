MirDB

A persistent Memcached-compatible key-value store

Built with Rust for performance and reliability. MirDB combines the simplicity of the Memcached protocol with durable disk persistence using LSM tree architecture.

Get Started

Key Features

Memcached Protocol

Full compatibility with existing Memcached clients. Drop-in replacement for your caching layer.

Disk Persistence

Data survives restarts. Never lose your cached data with durable storage to disk.

LSM Tree Architecture

Optimized for write-heavy workloads with efficient compaction and sorted string tables.

Built with Rust

Memory-safe and blazingly fast. Zero-cost abstractions for maximum performance.

Quick Start

Connect using any Memcached client. Here's an example using Python:

from pymemcache.client import base

# Connect to MirDB (default port: 12333)
client = base.Client(('localhost', 12333))

# Set a value
client.set('hello', 'world')

# Get the value back
result = client.get('hello')
print(result)  # b'world'
