MirDB

A high-performance, persistent key-value store with Memcached protocol compatibility and LSM-tree architecture.

View Dashboard Get Started

Key Features

💾

Persistent Storage

Unlike in-memory caches, MirDB persists your data to disk using efficient SSTables (Sorted String Tables), ensuring data durability across restarts.

🔌

Memcached Compatible

Drop-in replacement for Memcached with full protocol compatibility. Use your existing Memcached clients without any code changes.

📊

LSM Tree Architecture

Built on a Log-Structured Merge-tree (LSM) design with write-ahead logging, memtables, and multi-level compaction for optimal write performance.

⚡

High Performance

Asynchronous I/O powered by Tokio runtime, skip-list based memtables, and efficient block-based storage for blazing-fast operations.

🔧

Configurable

Fine-tune memory limits, compaction triggers, block sizes, and more through a simple TOML configuration file.

🧖

Written in Rust

Memory-safe, thread-safe, and blazingly fast. No garbage collection pauses, minimal runtime overhead.
