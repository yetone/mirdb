Introduction

A high-performance, persistent key-value store with native memcached protocol support.

Try It Now
mirdb-demo

Features

Memcached Protocol

Full compatibility with the memcached text protocol. Use existing memcached clients and tools seamlessly.

Skip-List Memtable

High-performance in-memory skip-list data structure for fast reads and writes with O(log n) complexity.

Compaction

Automatic minor and major compaction strategies to optimize storage and maintain read performance.

Persistence

Durable storage with write-ahead logging (WAL) and SSTable-based persistence for data safety.

Documentation

Installation

Build MirDB from source using Cargo:

# Clone the repository
git clone https://github.com/nicksrandall/mirdb.git
cd mirdb

# Build the project
cargo build --release

# The binary will be at target/release/mirdb-server

Configuration

Create a configuration file at etc/mirdb.toml:

# etc/mirdb.toml
listen_address = "0.0.0.0:11211"    # Memcached protocol port
http_port = 8080                     # HTTP server port
work_dir = "/var/lib/mirdb"          # Data directory
max_level = 7                        # Maximum SSTable levels
sstable_max_size = 104857600         # SSTable max size (100MB)
memtable_max_size = 4194304          # Memtable max size (4MB)
block_size = 4096                    # Block size for SSTable

Running the Server

Start MirDB with your configuration:

# Start with default configuration
./target/release/mirdb-server

# Start with custom configuration file
./target/release/mirdb-server --config etc/mirdb.toml

# Start with custom port
./target/release/mirdb-server --port 11211 --http-port 8080

Command Examples

MirDB supports the memcached text protocol. Here are basic command examples:

SET Command

Store a value with a key:

set mykey 0 0 5
hello
STORED

Format: set <key> <flags> <exptime> <bytes>

GET Command

Retrieve a value by key:

get mykey
VALUE mykey 0 5
hello
END

Format: get <key>

DELETE Command

Remove a key-value pair:

delete mykey
DELETED

Format: delete <key>
