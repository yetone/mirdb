Features

Memcached Protocol

Full compatibility with the Memcached protocol. Use your existing Memcached clients and tools without any modifications. Supports GET, SET, DELETE, and other standard commands.

LSM Tree Architecture

Built on a Log-Structured Merge-tree (LSM tree) architecture for high write throughput. Efficient compaction strategies ensure optimal read performance over time.

Persistent Storage

Data is persisted to disk using SSTables with write-ahead logging (WAL) for durability. Your data survives restarts and system failures.

Quick Start

Connect to MirDB using any Memcached-compatible client. Here are some examples:

Using telnet

# Connect to MirDB
telnet localhost 12333

# Set a key
set mykey 0 0 5
hello
STORED

# Get a key
get mykey
VALUE mykey 0 5
hello
END

# Delete a key
delete mykey
DELETED

Using memcached CLI

# Install memcached client (Ubuntu/Debian)
sudo apt-get install libmemcached-tools

# Set a value
echo "set testkey 0 0 11" | nc localhost 12333
hello world

# Get a value
echo "get testkey" | nc localhost 12333

Using Python

import memcache

# Connect to MirDB
client = memcache.Client(['localhost:12333'])

# Set a value
client.set('mykey', 'Hello, MirDB!')

# Get a value
value = client.get('mykey')
print(value)  # Output: Hello, MirDB!
