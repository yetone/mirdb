Welcome to MirDB

MirDB is a persistent key-value store built in Rust that implements the Memcached protocol with disk-based persistence using LSM-tree architecture.

Quick Start

Connect to MirDB using the Memcached protocol. Use telnet or netcat to interact with your data.

Connect to MirDB 
telnet localhost 12333
Alternative: Using netcat 
nc localhost 12333
Set a key 
set mykey 0 0 5
hello

Format: set <key> <flags> <exptime> <bytes>

Get a key 
get mykey
Delete a key 
delete mykey
