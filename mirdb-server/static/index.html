Features

SSTable Storage

Sorted String Tables provide durable, persistent on-disk storage with efficient key-value lookups using data blocks, index blocks, and Snappy compression.

Skip-List Memtable

High-performance in-memory skip-list data structure provides O(log n) reads and writes with efficient memory management and thread-safe operations.

Auto Compaction

Automatic background compaction with minor compaction (memtable to Level 0) and major compaction (merging between levels) for optimal storage efficiency.

Quick Start

Connect to MirDB using the Memcached protocol at 0.0.0.0:12333

SET - Store a key-value pair

# Syntax: set <key> <flags> <exptime> <bytes>
# flags: 32-bit unsigned integer (client-defined)
# exptime: expiration time in seconds (0 = never)
# bytes: number of bytes in the data block

set mykey 0 3600 5
hello
STORED

GET - Retrieve a value

# Syntax: get <key> [<key2> ...]

get mykey
VALUE mykey 0 5
hello
END

DELETE - Remove a key

# Syntax: delete <key> [noreply]

delete mykey
DELETED

Connect via Telnet or Netcat

# Using telnet
telnet 0.0.0.0 12333

# Using netcat
nc 0.0.0.0 12333
